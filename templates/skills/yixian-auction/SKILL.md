# 一线定乾坤·首板次日

交易日 09:25 筛选。昨日必须同时满足：首板；涨停前 DL_LOOKBACK 根中至少
DL_COUNT 次地量；涨停量超过 VOL_MA 均量；最近 JQ 根 KDJ 金叉且 K>D；
DIF、DEA 各高于配置下限；至少 MIN_BARS 根历史。今日只用开盘价，开盘涨幅
在 OPEN_MIN 与 OPEN_MAX 之间（含端点）。参数涨幅单位为百分数，例如 -5 表示 -5%。

在指标编辑器的参数表修改默认值并保存，手动选股和未设覆盖值的 09:25 定时任务
下次运行即读取新值，无须改脚本或重新部署。周期允许 1～1000；历史预热窗口随参数扩大。
行情库不足以填满指定条件窗口时不会伪造命中。

股票范围由系统股票池配置：仅主板；关闭 ST、退市、停牌名称/状态过滤；额外上市自然日
门槛为 0。公式内部不再含 CODELIKE/NAMELIKE，不附加行业、市值、股价、换手、宽度或 Top-N。
涨停参考比例 LIMIT_RATIO 默认 0.10，是原式主板计算口径；含 ST 不代表改用其特殊涨停比例。

使用原始不复权价格和实际成交量。指标函数复用系统 REF/LLV/SMA/EMA/ZTPRICE；
尚未做通达信客户端同输入数值对照。递推指标采用随周期扩大预热，不能宣称与从上市首日
起算逐位相等。本指标只筛选候选，不定义持有期、止盈止损或自动交易，也不承诺盈利。

定时窗口 [09:25,09:27)，检查交易日历；休市、报价缺失或迟到明确跳过/失败，不盘后补跑。
定时结果保留昨日条件、开盘涨幅、有效参数和实际抓取时刻。
