# 后端导览

## 定位信息

后端主要使用 Python、FastAPI、Pydantic 和 SQLite，运行依赖见项目依赖清单。
多数业务上下文按 `domain / application / infrastructure / api` 组织；`src/shared/` 提供公共能力，`src/app/` 负责装配。这是现状，不要求为简单功能强行添加多层文件。
身份与租户上下文由应用装配注入。账本、行情、策略、智能体和运维的入口可从相应上下文的 README 或路由继续定位，不必为每个任务读完整仓库。

## 与正确性相关的事实

租户路径通过 `ContextVar` 延迟解析；每租户的账本、运维配置和技能文件不是全局共享资源。路径与归属细节见根目录 `AGENTS.md` 和 `src/shared/paths.py`。
SQLite 与部分行情 SDK 是同步接口；在异步路由中调用时，考虑线程池或其他隔离方式，避免阻塞事件循环。
回测时间边界、行情单位、交易日和数据来源会影响结论。模型可以提出假设、生成代码、研究策略或调用工具，但预测、模拟值和已观察事实应能区分。

测试使用独立数据库、夹具或显式授权的隔离环境有助于保护真实账本。外部网络通常可用确定性替身替代；需要集成验证时标清环境、依赖和影响范围。真实秘密不属于源码或测试夹具。
已有交易算法、智能体提示词及数据结构是否需要调整由本轮需求决定，不因为 UI 重构而顺便改变它们。

## 验证工具（按需）

测试、静态检查和导入验证入口见根目录 `AGENTS.md`。

语法检查、导入冒烟、单元测试、接口测试和线上验证发现的问题不同。按实际改动选择组合，不设固定模型配额、工具调用次数、文件行数上限或机械检查清单。
