Loci 便携版使用说明
==================

这是绿色便携版：拷贝 Loci.exe 到任意文件夹，双击即可运行。
不需要安装程序，也不需要管理员权限（首次若提示安装 WebView2，按提示装运行时即可）。

数据存在哪
----------
默认写在「Loci.exe 同级目录」下的 data\ 文件夹：

  Loci.exe
  data\
    palace.db     账本
    market.db     历史行情（首次初始化后会很大）
    ops.db        运维配置
    skills\       技能包
  loci.config.json   你改过的数据目录等配置（有才会出现）

首次打开
--------
1. 确认或修改数据存放路径（可点「发现已有行情」复用别处的库）
2. 若该目录还没有历史日 K，会提示「初始化历史行情」，带进度条，可稍后再说
3. 以后可在「运维 → 数据目录」随时改路径；改完需重新打开 Loci
4. 换到空目录后，仍会提醒是否初始化行情

分发建议
--------
- 把 Loci.exe 单独拷给别人即可；不要把几 GB 的 market.db 打进压缩包除非对方需要离线行情
- 若已有完整 data\，可整夹拷贝到 exe 旁边，或在首次向导里指向该目录

打包（维护者）
--------------
  cd frontend && bun install && bun run build
  .\.venv\Scripts\python.exe -m PyInstaller --noconfirm loci.spec
  产物在仓库根目录：Loci.exe（与 data\ 同级）

  或：.\scripts\build-loci.ps1

桌面快捷方式
------------
  窗口菜单「帮助 → 创建桌面快捷方式」，或侧栏图标旁「帮助」。
