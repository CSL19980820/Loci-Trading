# 自主交易员：四区报告与独立周复盘

## 本轮交付

完整报告采用四个主区，不再用十几个逐股章节组成导航。日报侧重今日判断、持仓与关注、下一交易日计划、研究问题；周报侧重一周回顾、收益贡献与仓位、下周方向、研究进展。桌面双列、手机单列，使用原生 details 按需展开，完整文字与条件保留在页面内。模型可选 highlights 用于自拟标题的重点概括，没有经验条数、研究长度或对象数量上限。

独立阅读页入口是 `guardian_report_share.render_report_share`，调用 `guardian_report_dashboard.render_guardian_dashboard`。样式位于 `guardian_report_styles.py`。原有通用报告渲染及另一份阅读器未删除；其他智能体的调用保持兼容。

颜色明确按数值方向处理：正收益、上涨为红；负收益、下跌为绿；零值及未知值为中性色。青色只用于品牌和交互。金额显式标注元，底层仍为分。周权益曲线来自实际收盘序列，不插入虚构日内走势、指数数据或置信度。贡献表突出绝对贡献最大的四只，并明确展示其余合计及亏损标的数量；所有标的仍可在明细读取，净贡献不冒充因果归因。

## 周复盘独立配置

`guardian_weekly_prompt.py` 单独定义 `DEFAULT_WEEKLY_PROMPT` 和 `WEEKLY_REVIEW_TASK`。周复盘配置键为 `weekly_prompt`，通过 API、前端类型、设置抽屉及 PhasePromptEditor 贯通。

自主交易员设置有「共用基调 / 盘前 / 盘中 / 日复盘 / 周复盘」五个入口。周复盘只组合共用基调与独立周复盘内容；未设置时使用内置周复盘，不继承日复盘或盘中提示词。支持载入内置内容编辑和单独恢复默认。旧客户端未提交 weekly_prompt 时保留原配置，显式空字符串才恢复内置。其他智能体仍使用原四阶段编辑界面。

周复盘关注整周结果及其来源、资本配置演变、重要转折与重复决策问题、研究假设进展、下周重点，而非拼接日报或仅计划周一订单。按实际交易周与对应证据解释，不把期末仓位当周均仓位，不把单次获利当规律，不把策略纪律升级为自主账户必须遵守的命令。

`build_review_facts` 新增 `allocation_points`，从已经核对的期初及每日收盘账户生成现金、权益、仓位、持仓数量及逐股权重；不新增取价调用，不以期末快照倒推历史。

## 企微与历史内容

保留本工作区已有的独立短讯通道：正文预算560字节，优先独立 notification_summary，过长时使用可核对的成交简讯，不退回完整 summary 或 next_steps，也不分片刷屏。日周实际历史样本在测试入口下分别144和146字符，各一条。此数字是样本长度，不是对未来模型研究的字数限制。

页面不显示虚构的「企微已发送」，不自动改写报告判断或条件。已有静态分享快照的不可变发布机制未调整。
