## 按需读取与调用

- 保留完整账户资金、持仓、可卖股数、风险合同与执行规则。
- 所有候选仍有索引；重复的持仓正文只在账户中直接提供一次，完整候选仍存为证据。
- 近期轮次提供时间、状态、股票及回执数量索引。策略参数、完整订单、拒单、盘前计划及成交历史按 `evidence_ref` 读取，不删除原始资料。
- `guardian_context_read` 支持 JSON Pointer `path`、股票 `codes` 和字段 `fields`。`offset`/`limit` 为字符分页，续页须原样使用返回的 `next_read`。服务端拒绝省略前页筛选条件造成的错位拼接，不能把一页当全文。
- 报价、账户、时钟、计算器，以及市场概况、盘中个股资金、板块资金保留常用入口。其余工具由 `guardian_tools_search` 按关键词或精确名称加载，下一次模型请求收到所选工具的原始参数定义；不会重写或猜测上游 schema。
- 搜索支持中文部分词匹配及相关性排序，避免要求自然语言查询里的所有长词逐字同时命中。仍可空查询分页浏览全部目录。
- 外部查询继续使用既有 MCP 客户端及鉴权；本轮证据读取沿用进程内只读工具，不增加公网端口或新服务。
- 大工具结果保留完整回执和 SHA-256 证据，只向模型返回预览及读取入口。自主交易员使用 12,000 字符内联预算，其他调用者保留原有默认行为。

每次工具返回附上真实剩余研判时间；运行记录补充模型各轮起点、首个文本/推理增量、工具完成时刻、输入规模、已加载工具数。失败也保存这些信息与实际工具调用数量。

外部连接沿用 MCP 的初始化、`tools/list` 和 `tools/call` 契约，见 [MCP 工具协议](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。模型侧按需展开 schema，与是否存在该工具、是否授权调用是不同的状态。
