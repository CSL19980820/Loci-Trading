## 仓位与运行闭环

当前账户与 `simulate` 入口不按策略命中与否设买入门槛，也没有统一持仓只数、单票权重、总仓位比例上限。不能把这些既有能力说成本轮新建。

新增隔离回归从20万元临时模拟账户出发：池外买入100股，再在参考信号为“不买”的情况下追加19,400股，最终单票仓位超过97%；合法执行通过。现金不足的继续加仓和当日股份卖出仍被拒绝。这个比例仅检验可执行能力，不是系统目标、投资建议或收益证明。

运行链路为：研究与行情取证 → 独立决策 → 订单预检及有限修复 → 实际模拟成交/拒单记录 → 账户与风险合同更新 → 日/周复盘 → 带验证状态的研究交接 → 后续盘中重新判断。

本轮补齐的是复盘研究到后续判断的交接。旧报告不自动成为委托，也不要求继续服从旧策略；历史数量不适用时保留快照数量、要求以当前账户重估，不改写历史报告。未来才产生的更正不进入过去时点的上下文。近期预载窗口不是记忆总量，历史回读工具继续可用。

保留现金、费用、合法申报股数、可卖股份、行情时点、订单价格授权和租户隔离。这些描述真实执行条件，不替模型制定投资风格。已登记风险合同仍按明确更新、撤回及实际执行回执处理，不能以一句新叙述假装合同已不存在。

盘中270秒、复盘900秒的技术截止时间和提供方输出容量仍存在；研究没有固定轮次或单轮调用总次数配额。预检修复只修正已形成意图的执行问题，不把修复通道扩成静默加量、改方向或放宽价格授权的捷径。未修改采样参数、模型选择或生产调度。

## “天才交易员”与进化的证据边界

能取证、能自主选择、能推仓、能记录并回读复盘，不等于已经证明拥有持续交易优势。当前记忆是可回读和修订的研究记录，不是模型权重训练；经验的文本验证状态也不能代替长期样本外结果。本轮单元测试证明通道没有相关机械限制，不能证明模型以后一定选择正确仓位或稳定获利。

后续观察应区分：模型主动不买、历史规则误读、真实执行受阻；评价独立判断和资金配置质量，而不是策略服从度或是否够激进。不得用强制高仓位、必须成交、必须偏离策略等新纪律来冒充进化。
