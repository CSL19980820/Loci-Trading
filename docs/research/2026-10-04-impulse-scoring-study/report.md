# 大阳三日缩量突破：长期位置与趋势评分回测

日期：2026-10-04。研究对象：`impulse-inside-breakout-v1`，原策略 revision `builtin:impulse-inside-breakout-v1:3`。本轮仅离线研究，未修改线上策略、任务或账户。

**本轮五组固定方案中，“原评分70%＋位置与趋势修复30%”表现最好，值得作为下一版候选；单纯越低越加分没有稳定优势。当前证据尚不足以认定70/30为稳定最优或直接替换线上评分。**

候选在读行情前冻结，训练期先提名 `context70`，之后按原计划完整披露五组结果，没有根据后两段结果改权重。399笔原机会中，70/30只更换25笔；三段均改善，但2025下半年几乎只达到盈亏平衡，成本压力下仍亏损。

## 固定口径

- 数据来自既有生产只读快照 `.local/chinext-payoff-20261004/market.db`，2023-01-03至2026-09-30，共1,215,663条行情；快照SHA256：`c571588631c5a3bf475b1aaeabf650d475e979dba5adea8a9c17eb3556ea3d0c`。前后哈希一致。
- 创业板300/301，沿用原形态及全部硬条件。每组从完整合格候选重新评分，每天最多前二；四位总分裁决，同分代码升序。每天选股数量完全相同。
- 信号收盘确认、次日开盘买入，含买入日持有4个市场交易日，第4日收盘退出；先触及−6%则按原引擎止损，无固定止盈。遵守T+1、涨跌停/停牌限制，跳空穿止损按更差价格执行。
- 形态用前复权价格，成交用未复权价格，收益用经济权益因子。往返总成本0.21%，压力情景0.42%。
- 各时间段统一剔除无法容纳4日持有期的尾端信号。旧研究曾为20日退出网格采用20日成熟窗口，因此总笔数与旧报告不同；共同子集逐笔收益已复现一致。
- 本轮每组均170＋112＋117＝399笔闭仓交易，无未成交、`data_end`或跨段排除；成交均值等于原机会均值。独立事件回测，不是组合净值，也没有模拟资金占用和并发持仓容量。

## 五组评分

`S0`为原0–100分：整理收敛30、三日缩量25、突破放量25、当日收盘位置20。

位置定义在五根形态开始前，避免把大阳启动后的上涨当成原本就处于高位：

```text
P = [C(T−5) − 最近120日最低价(T−5)]
    / [最近120日最高价(T−5) − 最近120日最低价(T−5)]

B(P) = clip(min(P/0.2, 1, (1−P)/0.5), 0, 1)
R = 1，当 C(T)>MA20(T) 且 MA20(T)>MA20(T−10)；否则0
U = 1，当 R=1、MA20(T)>=MA60(T) 且 MA60(T)>=MA60(T−10)；否则0
```

`P`限制在0–1；120日窗口的高低价与收盘均截至T−5，`B`在20%–50%区间满分，向两端线性递减。趋势条件用信号日收盘，符合次日开盘入场时序。上下文缺失时所有改法均保留原分，不偷偷剔除候选；本次成熟候选没有缺失上下文。

| 方案 | 公式 |
|---|---|
| 原评分 baseline | `S0` |
| 简单低位 low80 | `0.8*S0 + 20*(1−P)` |
| 位置与修复 context70 | `0.7*S0 + 20*R*B(P) + 5*R + 5*U` |
| 纯趋势 trend80 | `0.8*S0 + 15*R + 5*U` |
| 轻量位置与修复 context80 | `0.8*S0 + 10*R + 5*U + 5*R*B(P)` |

其中70/30是整套评分方案比较；它也调整了原评分权重，不能把全部改善单独归功于“低位因子”。本轮未做大量参数网格，不能宣称70%或20%–50%是数学最优参数。

## 稳健性与风险

| 合并结果，每笔净收益 | 原评分 | 70/30 |
|---|---:|---:|
| 原成本0.21% | +0.220% | +0.439% |
| 成本翻倍至0.42% | +0.010% | +0.229% |
| 去掉最大盈利交易 | +0.062% | +0.280% |
| 成本翻倍且去掉最大盈利交易 | −0.148% | +0.070% |
| 最差单笔净收益 | −12.829% | −12.829% |
| 入场至退出日日线MAE均值 | −4.653% | −4.643% |

MAE按实际退出日结束，但包括退出当日整根日K；它不是成交前的精确盘中最大浮亏。本轮没有组合最大回撤结论。

分段弱点仍然明显：70/30在2025下半年的平均净收益只有+0.010%，成本翻倍后为−0.200%；该段去掉最大赢家后为−0.250%。合并正收益不能掩盖这一弱段。

按配对日收益差、整月为块进行5000次重采样（seed=20261004）：

- 合并33个月的平均改善为+0.218个百分点，描述性95%区间为[+0.010,+0.497]个百分点。但其中包含用于提名方案的训练段，不能把它当独立验证。
- **只看提名之后的2025下半年＋2026共229笔，平均改善为+0.116个百分点，95%区间为[−0.015,+0.262]个百分点，仍跨零。**
- 33个月中11个月改善、4个月退步、18个月选择收益未变。换股收益并非持续每月出现。

重采样没有消除历史规则开发、多方案比较或当前证券目录偏差，也未做多重检验校正。按训练结果提名方案再查看历史后段，仍不能代替未来新数据的验证。关于多次研究带来的过拟合风险，参考[Bailey等《The Probability of Backtest Overfitting》](https://scholarworks.wmich.edu/math_pubs/42/)。本轮没有估计该论文定义的PBO。

以下是**所有完整形态候选**按事先固定位置区间分组的平均净收益，属于解释性分组，不是另一套上线策略。

历史关系会变：前两段偏低位置较好，2026却相反。低价位本身不等于具备反弹能力，高位也不等于无法继续上涨。本轮更有希望的做法是“位置加分必须得到趋势修复确认，同时保留原形态主权重”；不是按位置永久压低高位股分数。

## 结论与证据边界

建议保留`context70`作为下一版研究候选，暂保留线上原评分。没有证据支持把“越低越好”直接作为统一评分原则；也没有必要在这份已观察历史上继续反复调整阈值追逐更漂亮结果。

数据采用当前证券目录与名称，没有完整历史成员记录，存在幸存者及成员偏差；复权因子是当前存档版本。2025下半年和2026在旧研究中已经看过，本轮所有区段均为历史复核，不是全新未见样本外。结论只覆盖本固定退出规则、成本和现有创业板样本，不外推到其他持有期或实盘资金规模。
