# A 股日频 OHLCV 候选：52 周高点接近度（PTH）动量

> **类型**：Explanation（只读外部研究）  
> **调研日**：2026-08-04  
> **范围**：提出一个只依赖日频 OHLCV 的研究候选；不修改策略、代码、配置、数据库或回测结论。文中“有效”均指论文作者报告的样本结果，不是本项目的已验证收益或生产授权。

## 结论

建议把 **52 周高点接近度**（price-to-52-week-high，`PTH252`）作为下一项只读回测候选，而不是直接纳入活动策略。

它在定义上与现有的 RSI 超卖低吸和三源尾盘形态不同：`PTH252` 是在全市场横截面上选择**最接近过去 252 个交易日高点**的股票，表达的是中期价格锚定/动量；不使用 RSI 阈值、次日回撤挂单或尾盘 K 线组合。首轮不把成交量加入 alpha 分数，避免把未经单独验证的过滤条件伪装成因子贡献。

中国证据存在，但边界很明确：一篇中国市场期刊论文的摘要报告，52 周高点动量在**低**经济政策不确定性（EPU）期间强、在**高** EPU 期间几乎不存在；另有一篇覆盖上交所 A 股 1995--2018 的 SSRN 工作论文报告正收益。前者说明该效应有状态依赖，后者是直接 A 股样本但尚应按工作论文处理。因此，候选应先做预注册的样本外回测，不能以全球文献或历史 A 股论文替代当前数据验证。

## 候选定义

### 因子公式

对股票 `i` 在收盘日 `T`，用同一复权口径的日高价与收盘价计算：

```text
H52_i,T    = max(High_i,T-251, ..., High_i,T)
PTH252_i,T = Close_i,T / H52_i,T
score_i,T  = 横截面 percentile-rank(PTH252_i,T)
```

首轮预注册选股规则为：在 `T` 日点时可交易股票中，`score >= 0.90` 的股票进入候选池，按 `PTH252` 从高到低排序并等权配置。`0.90` 是为首轮回测固定的十分位定义，不是已优化参数；不得在同一段样本中反复调整分位数、窗口或持有期后只报告最佳组合。

这里以 `High` 构造高水位、以 `Close` 衡量当前接近程度，是为了使日频 OHLCV 实现可复核。论文对 `PTH` 的经济含义是“当前价格/52 周高点价格”，但不同数据库可能以日高价或日收盘价定义高点；首轮必须额外做 `max(Close)` 版本的敏感性比较，不能把两种实现混为同一原始公式。

### 所需日频字段

| 字段 | 用途 | 是否进入 alpha 分数 |
| --- | --- | --- |
| `high` | `H52` 的 252 日滚动最高价 | 是 |
| `close` | `PTH252` 分子、收盘后发信号、持有期估值 | 是 |
| `open` | `T+1` 实际模拟入场价 | 否 |
| `volume` | 仅作零成交/流动性敏感性与成交可行性诊断 | 否 |
| `low` | 数据完整性和后续风险模型诊断；不参与基线信号 | 否 |

因子本身只需要 `high` 和 `close`，故属于 OHLCV 可实现的单因子。成交量若作为最小成交额或流动性筛选，必须作为**单独的执行约束**报告，并与无该筛选的结果并列，不能归因给 `PTH252`。

## 时间口径与防前视

1. **信号时点**：`T` 日收盘和当日最高价完整落定后才计算 `PTH252`，即盘后选股；不得在 `T` 日开盘或尾盘假设已知当日 `High`/`Close`。
2. **入场时点**：固定为 `T+1` 的 `open`。不得用 `T+1` 的 `low`、`high` 或收盘价决定是否下单；它们只可用于已入场头寸的事后估值/风险统计。
3. **滚动窗口**：每只股票至少有 252 根有效日线才有资格；窗口只含 `T` 及以前的行。新股、停复牌缺口和缺失值不补成可选标的。
4. **横截面**：当日排序只在 `T` 时点可得、满足最小历史长度的股票中进行。上市、退市、ST、板块与停牌状态若被用于限制股票池，必须来自点时（point-in-time）记录；不能用今日存活名单回填历史。
5. **复权一致性**：`High` 和 `Close` 必须使用同一种复权语义，禁止前复权收盘价与原始最高价混算。收益核算的除权、派息、停牌和退市处理也要冻结为当时可得口径，或单独证明不会影响该比率/收益。
6. **排名与资金**：`Top` 是显式按 `PTH252` 横截面排序，不得退化为代码顺序切片。买不到的候选不以更弱股票补位；保留空闲资金并计入组合收益。

日线 OHLCV 不能证明涨停板排队、集合竞价队列或临时停牌时能成交。把记录的 `T+1 open` 当作必然成交只能是乐观情景，不能作为可执行收益的唯一证据。

## 反证与失败风险

| 风险 | 为什么会推翻或削弱结论 | 最小应对 |
| --- | --- | --- |
| 宏观状态依赖 | 中国期刊证据已报告高 EPU 时动量几乎消失。[Zhou、Liu 与 Guo（2021）](https://doi.org/10.1080/1540496X.2021.1904880) | 即使基线不引入宏观数据，也要按熊/牛、波动率和政策冲击日期做事后分段；若没有稳定性，不进入候选池。 |
| 样本不可迁移 | 全球论文不是 A 股，直接 A 股的 Lan 等研究仅为 1995--2018 上交所工作论文。[Lan、Truong 与 Zhang（2026）](https://doi.org/10.2139/ssrn.6403338) | 将 2019 年以后、深市/创业板/科创板分别视为样本外，报告而非合并粉饰。 |
| 持有期方向改变 | 52 周高点可同时关联中期动量与短期锚点回归，文献机制并不保证任意期限同号。[Blau 等（2023）](https://doi.org/10.1080/15427560.2023.2244103) | 固定主检验 20 日持有，预先并列 5/60 日敏感性；不以结果优者回填主设定。 |
| 动量重叠 | `PTH252` 可能只是过去收益/突破强度的另一种编码，而非独立信息。 | 与 12 个月原始收益排序做相关性、双变量分组和增量收益比较。 |
| 涨跌停、停牌与流动性 | 日 OHLCV 没有订单队列和成交优先级；小盘高分股票的开盘可得性尤其可能被高估。 | 报告“记录开盘价可成交”的上界，并用独立可交易性资料做保守版本；仅凭日线不能声称解决该问题。 |
| 数据与公司行动 | 复权口径混用、幸存者宇宙、未来已知退市/停牌过滤都会制造前视。 | 保存数据快照、复权定义、每日股票池和剔除原因；纳入退市收益或明确报告缺失。 |

## 最小回测设计（只读）

以下设计的目的是判定是否值得进入下一轮研究，不是为寻找最高历史收益：

1. **预注册基线**：每 20 个交易日的最后一个交易日 `T` 形成一次组合；按当日 `PTH252` 选前 10%，`T+1 open` 等权买入，持有 20 个交易日后按收盘价退出。开始前固定窗口、分位数、调仓频率和持有期。
2. **股票池**：使用当时可得的 A 股历史股票池；每股至少 252 根一致复权日线。对停牌、零成交、上市未满 252 日、退市和无法成交情况逐项统计，不把事后仍存活的股票当成历史宇宙。
3. **比较组**：同时报告全宇宙等权、`PTH252` 后 10%、12 个月原始收益前 10% 三组。这样才能识别高点接近度相对市场、相对反向组和相对普通动量是否还有信息。
4. **成本与可成交性**：使用交易日对应的实际费率（佣金、印花税、过户费等）；费率资料不足时至少做明确的双边成本敏感性表。资金按真实持有期占用，遇到不可成交不换入弱候选，闲置资金收益按零或明确的现金利率计。
5. **样本外优先**：Lan 等工作论文报告的上交所样本止于 2018，因此有足够数据时把 2019 年以后独立列为样本外；如果本地数据只覆盖短窗口，结果只能称探索性，不能称复现。
6. **必报指标**：样本交易/持仓数、胜率、平均毛/净收益、中位数、平均盈利/亏损与盈亏比、Profit Factor、最大回撤、年化/累计组合收益、资金占用和闲置现金、无法成交比例；按年度、月份和市场状态分段。禁止把同日信号收益直接相乘来代替有重叠持仓的组合回测。
7. **通过门槛**：不以单一累计收益决定。至少要求样本外相对比较组有一致方向、扣成本后仍可解释、没有单一月份/行业/极端涨停样本主导，并能说明与现有策略的持仓重叠和增量价值；否则维持现金，不新增策略。

## 研究边界

本笔研究只给出来源、候选公式和可证伪的回测方案。它没有运行本地回测，没有检查本地 OHLCV 覆盖，也没有修改任何活动默认值。只有在上述点时股票池、可成交性和样本外检验完成后，才可以讨论是否把 `PTH252` 作为自定义策略或与其他因子组合。
