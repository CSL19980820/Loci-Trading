# 量化平台产品与社区化对标（2026-08-27）

> 调研日：2026-08-27。覆盖 18 个平台（国内 9 + 国外 9），以官网/官方文档为准。
> 与 `2026-08-mainstream-quant-benchmark.md` 分工：那篇对标**开源体系的工程分层**
> （数据/因子/回测/组合/执行/实验），本篇对标**商业平台的产品面与社区面**
> ——策略广场、克隆按钮、排行榜、跟单、订阅、行情大屏。
> 结论落到 [ADR-015](../adr/ADR-015-v2-multi-tenant-identity-and-community.md)。
>
> 图例四态：✅ 官方明文｜⚠️ 部分/间接（企业版、关联产品、第三方生态）｜
> ❌ 本轮未在官方口径中找到且从定位判断大概率没有｜❓ 未核实（站点 JS 渲染 / 403 / TLS 拦截）。
> **「❌」当「不确定偏无」读**——国内平台大量功能藏在登录后的控制台里。
>
> 免责：仅供产品与工程决策参考，不构成投资建议。功能随版本变动，判断锁定在调研日。

## 1. 三个最重要的发现

### 1.1 国内没有一家把「社区」和「引擎」同时做透

- 聚宽有**克隆按钮**但没有排行榜与订阅；
- 果仁网有**排行榜 + 按月订阅**但没有编程编辑器与开放 API；
- 同花顺 SuperMind 功能最全，但社区是附属品；
- 雪球社区最强，但**根本没有回测**。

「广场 + 引擎 + 榜单 + 变现」四件套齐活的国内平台，本轮一个都没核到。
这是我们的机会窗口。

### 1.2 排行榜是国内外差距最大的一格

| 平台 | 排序口径 |
|---|---|
| QuantConnect | `score = 一年 Sharpe × 样本外折扣`（不足一年按在样本内的时间比例线性打折，样本内 6 个月直接砍半） |
| Collective2 | 收益口径**含订阅费 + 每笔 AutoTrade 费 + 券商佣金**，并单独说明最大回撤算法 |
| Numerai | 按**质押金额加权**；亏损部分的代币直接销毁（不进平台口袋也不给别人） |
| 国内九家 | 基本是**裸收益率排序** |

裸收益率榜的三种必然结局：过拟合刷榜、单押高波动、多开小号。
**我们采用 QuantConnect 口径**（见 `src/community/domain/scoring.py`）。

### 1.3 跟单这一列国内全是 ❌/⚠️——是牌照原因，不是技术原因

果仁网把话说得最直白：订阅者拿到的是**调仓指令**，「并不能得到策略的定义」，
执行靠自己。A 股自动跟单等于代客理财。
**我们照此办理**：`subscriptions.mode` 只有 `signal_only`，DDL CHECK + API
schema + domain docstring 三处兜死。

## 3. 社区化玩法深挖（6 例）

### 3.1 TradingView：脚本广场 + Boost + 三态审核

Pine Script 社区已发布 15 万+ 脚本、约半数开源。发布时选可见性
（open-source / protected / invite-only）× 范围（public / private）；公开脚本
先只在个人主页可见，版主审核后落入 **Suggested**（进社区 feed）/
**Unsuggested**（只留主页）/ **Hidden** 三态之一。

**技术要点**：
1. **排名信号与内容质量解耦**——boost（点赞）决定「热」，版主三态决定「能不能
   进 feed」，两条独立管线，避免纯点赞驱动的劣币。
2. **回测可信度写进规则**：必须用真实初始资金、真实佣金与滑点、真实保证金
 （`margin=0` 视为无限杠杆，禁止）；一般要求 >100 笔成交；禁止在
   Heikin Ashi/Renko 等非标准图上发信号类脚本；禁止 `barmerge.lookahead_on`
   造成的前视。
3. **代码复用有强制署名与开源传染**，闭源被质疑抄袭要 4 小时内自证。

→ 我们抄了第 2 条，做成机器可校验的 `domain/publish_rules.py`。

### 3.2 Numerai：众包 Alpha + 质押激励

平台买对冲基金级数据后**做混淆**（特征名、股票 ID、跨 era 不可对齐）免费发放。
双指标计分：CORR（与目标相关性）与 **MMC（对元模型的边际贡献）**。
可选质押，亏损部分的 NMR **直接销毁**——机制上消灭平台与用户的对赌。

**对我们**：整套抄不了（没有基金、没有代币），但 **MMC 可以退化成一个零成本
指标：新战法对现有战法池的边际贡献**（剔除相关性后的增量 IR）。这比再加一个
收益率榜有价值得多。→ 列入遗留项。

### 3.3 Collective2：AutoTrade 全自动跟单

核心是 **AutoSync**：持续比对「账户实际持仓」与「按设置 + 策略记录应有的持仓」，
网络中断、券商宕机恢复后自动补齐差异——本质是幂等的持仓 diff-and-reconcile 循环。

**对我们**：跟单本体不做（合规），但 AutoSync 的「期望持仓 vs 实际持仓 diff」
模型可直接复用到纸面盘/实盘对账。

### 3.4 eToro CopyTrader：平台反向付费

Champion 档起**由 eToro 按被复制资产付钱，年化 1.5%、按月发**。
准入门槛**全是风险与合规指标而非收益指标**：日风险分 ≤7、周最大回撤 ≥ −25%、
单一持仓 ≤50%、盈利月份占比 ≥30%、每月至少一篇 ≥100 词动态。

**对我们**：「风险门槛 + 内容义务」两个准入条件几乎零成本，可直接搬进上架规则。

### 3.5 聚宽：社区帖即策略 + 克隆按钮

社区帖页面直接带「克隆策略」按钮，一点即复制进自己的研究列表。
**克隆成立的前提是「策略是自包含、可重跑的对象」**：代码 + 参数 + 回测区间 +
数据依赖，缺一样克隆过去就跑不起来。用积分给克隆定价，把白嫖变成有摩擦的行为。

**对我们**：克隆是所有社区化功能里性价比最高的一个，但成本不在按钮，
在**战法产物标准化**。

### 3.6 果仁网：国内唯一跑通闭环

零代码因子选股 → 秒级全量回测 → 申请认证（算法评估相似度 + 人工审核投资逻辑）
→ 进策略集市按月订阅 → 微信服务号推调仓指令。

四条值得抄：
1. **「历史回测收益 + 创建后收益」两段展示**——国内最朴素也最有效的反过拟合叙事；
2. **上架即冻结**（上架后不能修改或删除）把策略变成有版本、有承诺的商品；
3. **单策略订阅人数与可容纳资金量设上限**——把「策略容量」当一等产品概念；
4. 订阅只给指令不给定义，绕开卖代码的 IP 与合规问题。

→ 我们抄了 1、2、4（`published_versions` 挂 BEFORE UPDATE/DELETE 触发器）。

### 3.7 QuantConnect Strategies：把排行榜做成防过拟合门禁

平台**每天替所有人重跑一遍回测**，看到的是持续更新的样本外表现。
上架硬性规范：回测不能报错、**不许 try/except**、区间固定最近 5 年、
运行 <1 小时、**必须用默认的手续费/买力/期权行权模型**（明令禁止改手续费、
加杠杆、关行权来美化）、回测中不许出入金。

这是本轮见到的**最好的排行榜设计**——同时解决三件事：样本外靠「每日重跑」
自动积累、过拟合靠「score 折扣」定价、作弊靠「禁止改现实模型」堵死。

## 4. 实时大屏 / 行情墙的业界做法

| 形态 | 刷新频率（业界口径） | 技术要点 |
|---|---|---|
| **涨跌分布热力图** | Finviz 免费档延迟 1 分钟；A 股受 Level-1 约束物理上限 **3 秒** | treemap + 一次拉全市场截面 + **增量 patch 颜色**，不整树重排；面积用**前一日收盘市值**避免每 tick 重算导致抖动 |
| **跑马灯/行情条** | 3–15 秒 | **动画与数据必须解耦**（数据到了只换文本，不重启动画）；定长 DOM 池复用；`visibilitychange` 离屏即停拉数 |
| **龙虎榜滚动** | **日频**——收盘后披露，盘中刷新无意义 | 收盘后一次性入库 + 前端静态分页，不占实时通道 |
| **盘口异动实时流** | **A 股上限 3 秒**（Ptrade 明写 tick 最小粒度 3s；QMT 明写盘中每个分笔三秒触发一次） | 事件抽取在服务端做，**绝不把原始 tick 推浏览器** |
| **板块资金流** | 分钟级是商业数据常规档，tick 级是加钱档 | 资金流是派生指标，**口径各家不同，大屏必须标注口径与来源** |

> 号称「毫秒级 A 股异动」的，要么用了 Level-2 逐笔，要么在吹牛。

**我们的刷新频率预算**：3s（盘口异动流、持仓盯盘，SSE）/ 15s（跑马灯、信号池）/
60s（热力图、板块资金流，轮询）/ 日频（龙虎榜、复盘墙、榜单）。

**三条实现纪律**：① 原始 tick 不出服务端；② 动画与数据解耦；
③ **每块都要标 `as_of` 与来源**——我们本来就有溯源回执，大屏上不显示数据时间戳
等于把最强的资产藏起来。

## 6. 明确不建议做的五件事

1. **自动跟单执行** —— 牌照问题，不是技术问题。
2. **策略付费撮合与支付** —— 支付通道、发票、资质、退款纠纷，成本远超本阶段承受力。
3. **拖拽式可视化建模** —— 优矿/果仁做得好是因为它们的用户不写代码；我们的用户
   （和 AI 助手）写代码，投入产出比极低。
4. **多语言 SDK** —— 全场只有三家做了，且都是为了迁就存量用户，我们没这个包袱。
5. **自建 Level-2 实时异动** —— A 股 Level-1 的 3 秒上限决定了投入 Level-2 才能
   拿到增量，成本量级完全不同。**先把「当天不存就永久丢失」的快照存下来，
   比做大屏紧急得多。**

## 7. 取证受限说明（必须连同结论一起读）

| 平台 | 情况 |
|---|---|
| 聚宽 | 站点纯前端渲染，只有 `/data` 是服务端渲染。因子库与数据字典是一手证据；**克隆按钮、积分/VIP、运行时分离三条来自官方域内搜索摘要**，证据等级低一档 |
| 掘金 | `www.myquant.cn` 与 `/docs*` 全部 403。改用官方 PyPI 包 `gm` 的说明与 changelog 取证，只覆盖 SDK 能力 |
| 雪球 | 直读一律 TLS 证书校验失败。结论来自中文维基 + 域内搜索摘要，**请当「官方域内二手」而非一手** |
| 同花顺 | HTTPS 证书校验失败，改用 http:// 直读成功，证据等级正常 |
| Collective2 | 主站 403；`api.collective2.com/about-autotrade` 可直读（AutoTrade 全部特性都在这一页） |
| 东方财富 | 三次连接超时，本轮**未取证**。§4 的龙虎榜与板块资金流口径改用掘金 SDK 与米筐企业版文档佐证 |

`web_search` 供应商间歇性全线失败，部分查询重试若干次才成功。
因此「没搜到」不构成「不存在」的证据——这也是保留 ❓ 而不是填 ❌ 的原因。
