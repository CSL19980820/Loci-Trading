# 二次突破日均价位置 A/B：待冻结执行合同

本文件与[共同计划](../2026-10-04-vwap-study/PLAN.md)共同约束实验。代码、自检和本文件审阅后，单独执行 `freeze` 写入源码、只读快照、两个计划的 SHA256；只有此后授权的 `run` 才计算收益。保留旧研究的源码、计划和结果，正式策略、生产、账本和调度不变。

## 候选与日均价

沿用 `contraction-rebreakout-v1` 原六个形态条件、五项评分及评分四位小数。复用已校正的完整形态重建函数：直接从快照 SQL 读取截至该日的权益因子，只前向对齐；信号价格使用十位有效数字，严格涨跌停参考使用统一经济坐标。未经校正的原行为独立保留为控制。没有新形态、模型、行业门槛、持仓去重或冷却期。

突破日 T 收盘后才读取同一 `quotes_daily` 行的 amount、volume、source、OHLC。资格要求 source 精确为 `tdx`，amount、volume、low、high 有限且为有效正数，high≥low，`VWAP=amount/volume` 位于 `[low−0.01,high+0.01]`。仓内单位已核验为元/股，不再次乘除100。不补金额、不把缺失或未知提供商当0。SQL原价和量必须与信号执行面板逐值一致。

`H5=max(high_economic[T−5:T−1])`，`VWAP_economic=precision10(VWAP_raw×factor_T)`，`C_economic=precision10(C_raw×factor_T)`。唯一额外门槛为 `H5<VWAP_economic<=C_economic`。它描述日成交均价相对前五日最高价及收盘价的位置，不证明主动资金、主力行为、持有人成本或盘中承接。

## 三个控制与两个政策

| 名称 | 候选与排序 | 入场 |
|---|---|---|
| legacy_original | 旧实现已经选定的原名单 | 原次日开盘 |
| corrected_original | 技术校正后的完整原形态，原分数 | 次日开盘 |
| vwap_eligible_original | corrected_original 完整池中日均价资格已知者，原分数 | 次日开盘 |
| A / vwap_gate_open | 资格已知且通过唯一日均价门槛，原分数 | 次日开盘 |
| B / vwap_gate_limit | 与A完全相同的名单 | 次日一天限价 |

除 legacy 的原实现控制外，先过滤完整池，再以原分数降序、代码升序固定选Top2。全体预选 CSV 及哈希回执必须在该段任何收益标签计算之前落盘。不得按未来是否成交、收益、退出或数据完整性预筛名单。A/B和B压力名单键必须逐行完全一致，任何取消均不补位。

B的限价在T收盘固定为日均价向下取整至分。使用 `Decimal(str(stored_amount))/Decimal(str(stored_volume))` 的十进制商，乘100后 `ROUND_FLOOR` 得整数分；不先量化几何价格，不以浮点乘100后向下取整，不用T+1因子倒改前一日限价。

## 执行与未知

继承原次日执行保护：已知日量≤0取消，已知涨停开盘取消；未知量、无效开盘或未知涨跌停参考记未解决，不能填0。所有政策使用真实未复权开盘、原始量及直接读取因子。B若隔夜因子发生变化（绝对容差1e−10）取消，不补位。

B开盘≤限价，按更低的实际开盘代理成交；否则，当日最低价≤限价，按限价代理成交；已知低点未触及则当日取消。低点未知且开盘分支未满足记未解决。日K不能证明排队、部分成交或实际订单成交。仍沿用原涨停开盘取消保护，即便当日稍后可能开板也不再接受该日订单。

唯一一分钱压力 `vwap_gate_limit_one_tick` 只收紧**非开盘分支**为最低价≤限价−0.01，成交价仍是原限价；开盘≤限价分支保持按开盘，不因事后最低价否决。压力使用基础往返成本0.21个百分点，不与加倍成本混淆。压力未知、未退出同样阻止通过。

所有控制和政策固定持有4个市场交易日（含入场），止损−6%，无止盈，沿用原退出解析器的T+1、跳空更差开盘、停牌及跌停延后退出合同。收益用未量化的实际原价×直接因子。已成交后任何影响退出路径的缺失日量或有效交易日无效OHLC/参考，均记未解决；不把缺失当已知停牌，也不因后面恰有有效退出而忽略未知止损日。已知停牌日继续延后。未平仓/data_end不当0，不能通过验收。

## 预算、压力和有限选择

共同日历为每段全部市场交易日中满足 `T+4<=段末` 的信号日，每日2名额；所有控制、政策、压力完全同分母，包括没候选及没出手日期。无订单、已知取消的名额贡献0，已选未知使整个名额均值及置信区间不可用。独立事件账本不新增现金、持仓去重，不能解释为账户净值；共享资金验证由根研究另行执行。

每段保存基础成本0.21、成本0.42、删除基础净收益最大赢家、成本0.42并删除同一赢家四组指标。赢家按基础净收益最大值确定，两个删除压力使用同一个订单；保留完整日历分母，不能缩小分母制造优势。报告平均净收益、PF、胜率、交易数量、入场月份、共同名额贡献及相对 corrected_original 的按月配对区间。

训练2024-01-01至2025-06-30，只可从A/B各一个中入围：至少20笔闭合、至少6入场月、无已选未知、净均值>0、PF>1、双成本并删最大赢家净均值>0，且共同完整日历名额均值严格胜 corrected_original 和 vwap_eligible_original。B还须一分钱压力净均值>0且无未知。仅正收益无亏损时PF按无穷大语义通过；输出PF仍为null并显式显示正负收益总额。两者均不过则STOP，无诊断兜底、再选阈值、窗口、分数或退出参数。

只有训练入围者才运行2025H2及2026-01-01至2026-09-30，并包含必要控制。若仅B入围，仍保留同名单A次日开盘执行作机制控制，标记不可重新提名；它不能因后段好看恢复资格。各后段至少12闭合、4入场月、净均值>0、PF>1、名额均值严格胜两个控制且无未知；合计至少40笔，双成本并删除合计最大赢家净均值>0。B在每个后段的一分钱压力也须净均值>0且无未知。

A/B逐订单并列表显示B成交/取消与对应A机会收益，区分限价改善和放弃机会；这种分组为已冻结名单的解释，不产生新政策。只检查本家族A/B，不增加探索网格。
