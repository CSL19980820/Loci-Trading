## 3. 方向结论（给你拍板）

1. **最强方向不是新零售甜区，而是「潜龙尾盘信号 + 弱市空仓(≥35%) + 止盈略抬到 3.5%」** → 连乘约 +92%、PF≈2.6。  
2. **用户公式族里能打的是**：紧均线尾盘 **∩ 黑马十日大阳记忆 ∩ 宽度 ≥35% ∩ 评分 Top1 ∩ TP4**（约 +71%、PF≈2.0），不靠瞎抬门槛。  
3. **仅主板 + 无止盈** 也能冲连乘，但胜率掉到 ~53%，路径更抖。  
4. 纯尾盘原式 / 甜区 / 无宽度：批量里大量翻车，之前单独测翻车不是抽样运气。
