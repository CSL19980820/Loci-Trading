# 倍量阴：市场环境与个股趋势许可研究（2026-10-04）

**五臂训练均为负收益，本机制家族到此停止，没有入围方案，也没有计算这些方案的2025H2/2026收益。** 市场弱时亏损更大，但仅凭市场转强、个股中期趋势与相对强弱，尚不能把倍量阴变成正期望交易。减少交易带来的少亏不等于获得可靠收益。

本轮先冻结两种对照和3种机制，11项合成检查及独立静态审查后才计算训练收益。此前区间已有其他研究结果，因此不称为未触碰的样本外验证。完整形态本身也有资格参与最多2项提名；本次它同样不合格。

## 比较和信号定义

五臂全部保留强阳→倍量阴的原历史形态、主板/非ST/名称与有效历史约束，实际买入原价>6，行业组任意交集去重后Top2。先在全候选池施加许可，再重排，未对旧Top2事后过滤。

| 臂 | 固定定义 | 因果归因对照 |
|---|---|---|
| 价格校正原低开 | 保留原T日低开、60日低位60分/MA5、10、20接近度40分 | 原行为基准 |
| 完整形态 | 取消T低开要求；其他形态、开盘原价>6、评分和退出相同 | 取消低开本身可提名；也是后3臂的控制 |
| M | T-1沪深300收盘>MA60，且主板收盘>MA20宽度≥50% | 完整形态及原低开 |
| S | T-2个股收盘>MA60、MA20>MA60，且20个市场日回报强于同端点沪深300 | 完整形态及原低开 |
| M∩S | 同时满足M与S | 完整形态及原低开 |

窗口只用预固定20/60，分界为0/50%，没有参数或退出网格。退出统一为含入场4个市场日、-6%止损、严格T+1；跳空按更差开盘、停牌/跌停顺延，手续费税费滑点合计0.21%。共同成熟窗口为T+3≤区间结束；每个合格市场日2个槽位，空闲也保留。

市场宽度来自全部3195个STOCK类型、00/60主板代码，与形态候选无关；明确排除INDEX类型000300。训练截止有3150代码至少20条数据，每日分母只包括当时连续20个市场日有正价和正量者，区间分母3053～3127。当前ST/名称不额外缩小宽度分母；历史新股在历史不足时不能进入分母。沪深300暖机到训练末共有601日、无缺口、来源tdx。

## 数值精度修正

此前代理通过hfq_close/raw_close反推因子，会因约1e-15误差把相同原价误作涨跌。本轮从只读快照直接读取实际hfq_factor，只向前对齐；存在报价却没有先前因子就失败，不用未来值回填。信号价格和被比较的均线统一到10位有效数字，逐项约束误差小于0.0001个原始分币跳动；实际成交和收益仍是未舍入原价×真实因子。

相同原价/相同因子必然平价。已确认旧误例002868/2024-09-25没有进入本轮低开控制。全部五臂重新计算，未复用之前受精度影响的控制收益；全形态评分对所有开盘有效候选重算，并逐行与低开子集原公式一致。数值修正单独归为正确性，不算环境信号创造的收益。

## 训练内诊断能解释什么

以下只用于解释原低开控制的条件差异，不将每一格视作新策略，也未据此重新筛选方案。

| 原低开交易的条件 | 条件不满足：笔数/均值%/PF | 条件满足：笔数/均值%/PF |
|---|---|---|
| 沪深300 > MA60 | 218 / -1.576 / 0.571 | 295 / -0.313 / 0.899 |
| 主板MA20宽度≥50% | 270 / -1.316 / 0.649 | 243 / -0.331 / 0.885 |
| 主板上涨比例≥50% | 287 / -1.673 / 0.552 | 226 / 0.196 / 1.069 |
| 个股C > MA60 | 108 / 0.051 / 1.018 | 405 / -1.090 / 0.685 |
| 个股MA20 > MA60 | 265 / -0.556 / 0.820 | 248 / -1.163 / 0.677 |
| 个股20日跑赢沪深300 | 88 / 0.338 / 1.124 | 425 / -1.096 / 0.684 |

市场偏弱与训练期较大损失相关，但指数和MA宽度转强后原低开均值仍为负。个股先前趋势更强或相对表现更强，并没有保护策略；这也说明倍量阴不能自动解释为强股洗盘。上涨比例≥50%这一描述组仅+0.196%，连额外0.21%成本都不能覆盖；不把事后看到的微正分组升级为新门槛。

全部1301个候选按同一退出独立诊断的均值为-0.601%、PF0.822。M0/S1（弱环境中的前期强股）313笔均值-1.905%、PF0.552；M1/S0为198笔+0.208%、PF1.077，但同样无法承受加倍成本，且这只是预列分组，未构造新的反向S策略。市场许可更像减少负收益暴露，未证明稳定正收益。

这些训练内相关性不能直接证明此前2025H2盈利的原因。本轮没有为解释已知盈利区间而查看新规则的后段分组、调整阈值，或把后段结果反过来当作训练目标。

## 还缺什么信息

现有日K只能记录倍量阴发生后的价格与总量，难以分辨集中派发与真正承接，也不能重建09:25可成交条件。若继续提出新的收益机制，应先取得可按当时时间截断的证据，例如竞价成交额/换手与委托不平衡、开盘后固定窗口的真实承接及后续可成交价，或者可追溯的催化事件/行业当时强弱。必须明确采集时间、实际执行延迟与新增信息，再冻结有限假设；继续换20/60为别的窗口不会补上这些事实。此处没有宣称上述信息一定能带来收益，也没有扩展本轮回测。
