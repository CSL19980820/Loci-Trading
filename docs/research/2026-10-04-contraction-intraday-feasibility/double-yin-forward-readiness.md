# 倍量阴 B：真实开盘前瞻验证的输入就绪度

2026-10-04，只读调查。保留 B 候选和原严格验收失败结论；本调查没有实现新策略、改任务或采集数据，也不是增强成功证据。

**现有系统已经有“盘后完整形态池 → 次交易日 09:25—09:30 全池现场开盘确认”链路，可复用；但现有产物还不足以原样验证研究 B。** 主要缺口是研究与现役形态的复权坐标一致性、昨日真实成交额和逐条因子封存、全候选开盘事实的持久留存，以及确认开盘价之后的成交证据。

## 已有能力与边界

| 环节 | 当前实际能力 | 对 B 的含义 |
|---|---|---|
| 完整形态池 | `prepare_double_yin_pool` 取 `历史形态候选`，不是低开后的 `条件候选`；标记 `complete_before_open_filter`、`pre_ranked=false`。不预先 Top2，保存全部历史样本、名称、行业和参数/范围摘要。 | **现盘后池没有先过滤低开，不能误称只剩旧低开股票。** 可复用完整池流程；不要从晨间旧低开候选或正式精选池生成 B。 |
| 形态价格坐标 | 当前准备方法 `adjust="none"`，引擎按 raw OHLC 判断历史形态；研究 B 则以直接历史权益因子的共同经济坐标、10 位有效数字判断形态和评分，原价判断当日 `O>6`。 | 现盘后池尚不能保证等于研究完整形态池；跨权益变化可能增删候选。先证明坐标和全池一致性，不能只在该池上补一个 VWAP 条件就宣称复现 B。 |
| 昨日 VWAP | 行情仓已有 `amount`、`volume`、`source`、`receipt_id`、`fetched_at`，`load_panel` 已能读取原始 `amount`。现役引擎 `required_fields()` 只有 OHLCV，准备池历史也只封存 OHLCV。 | 不缺基础取数字段/接口，缺的是把昨日原始金额、股数、逐行来源及可用时间纳入独立输入凭据。不能从日K收盘价补成交额。 |
| 开盘时点 | `fetch_double_yin_openings` 对准备池全部股票调用新浪接口，20 秒重试预算；要求同一交易日、源时间 `09:25≤t<09:30`、有效真实 open、正竞价量和前收，拒绝用现价补 open。源时间超现场时钟 5 秒也拒绝；缺一只就不把剩余样本当完整排名，完成时不能跨 09:30。 | 已有候选级现场开盘边界，**无须另造全市场实时服务**。但这是报价事实，不是决策后订单能以该开盘价成交的证明。 |
| 行业 | 盘后逐候选查询东财 EM2016，保存原行业路径、所有去重 groups、source 和 fetched_at；未知分类不按名字猜。 | 未来逐日冻结这份实际获得的映射可支持当时的行业去重。当前查询不是历史行业版本库，不要把今日映射倒称过去当时已知。 |
| 因子与前收 | 准备池保存全库因子摘要/hash，未保存候选逐日因子；晨间以源前收与历史 raw 收盘差不超过 0.005 检查口径，部分不一致者不参与计算。通用 `_factor_panel` 仍有 bfill/缺失填1语义。 | 不能用全库摘要重建当时的共同坐标，也不能直接把通用复权默认行为当作研究的“仅向前对齐、不用未来值”合同。已有 `adjust_factors(code,trade_date,hfq_factor,source,fetched_at)` 可供有边界读取和冻结。 |
| 已保存开盘证据 | 晨间确实先抓全池；但成功结果的 `candidate_reviews` 仅含旧低开条件候选，逐股票 `live_quote` / `selected_quote_evidence` 仅保存精选，其他股票仅有总覆盖率和源时间范围。缺报价时上层抛出含前5只原因的错误，未把完整 quote_snapshot 附入成功结果。 | B 可选的非低开股票报价在本链路中没有完整封存，不能事后从原精选结果恢复 B 的全池排序。可复用抓取函数已返回的全量 quotes / rejects / coverage，独立留存成功和失败凭据。 |

## 最小可验证下一步

1. **先做输入封存与等价性验收，不重跑收益。** 从既有盘后行情与准备流程形成独立研究凭据，核对研究 B 的完整形态坐标/成员、昨日 amount/source 和逐条因子；保留旧任务及其池。发现 raw 池与经济坐标池不一致时，列明差异来源，不把旧池当作 B 的完整池。
2. 在下一次真实开盘窗口，以该完整池复用 `fetch_double_yin_openings` 做一次独立影子记录验收：每只请求均有终态、源时点合格、原始字段与来源完整、全池输入可由 hash 重放。当前接口/20秒重试/失败覆盖证据可直接复用；新增内容只需围绕上述凭据，不需要新通用实时框架。**本次没有启动采集、创建任务或预约运行。**
3. 全池因果输入验收通过，只能称“B 真实开盘候选可验证”。若随后要检验可实现收益，先单独冻结决策后执行/退出/费用合同及前瞻评价日期，再积累真实未来样本；不沿用日K同价成交作为现实成交，不将本调查或一次成功取数写成策略增强成功。

后续做一次固定“已知开盘条件后 09:35 代理入场”的执行敏感性有必要：它可以检验 B 是否过分依赖同价开盘成交假设。按根任务另行核验的 TDX 历史数据边界（240 个 price/vol 采样点、没有源时间/OHLC、由程序分配分钟槽），该试验只能称固定时间槽代理，不能写成真实源 09:35 成交；与 Sina 部分价格相同也不能证明逐分钟时点一致。若另行授权，应先固定唯一入场时点、缺失/停牌/涨跌停处理及原候选名单，按代理入场价重新计算 T+1 后的止损、退出、费用与资金占用，不能只替换入场价却沿用旧交易收益。它仍是已观察历史上的事后敏感性，不是新样本验证，也不能自动撤销 H2 严格失败。本次未为该建议发起请求、读取新收益或修改规则。
