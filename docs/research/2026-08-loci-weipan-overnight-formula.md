## 3. 凝练（Loci 自有尾盘隔夜公式草案）

### 3.1 命名与定位

- 工作名：**`loci-weipan-overnight-v0`（Loci 尾盘隔夜 V0）**
- 定位：与 `qianlong-tail-v1` **平行的候选袖**（不替换潜龙核心突破）；专做「温和强势日 → 隔夜 → 次日冲高兑现」。
- 执行：`entry_timing = close`；技术面板 `qfq`；成交 OHLC `none`（对齐潜龙尾盘）。

### 3.2 公式（日线可实现；禁止未来函数）

记：

- `r1 = CLOSE/REF(CLOSE,1) - 1`
- `vol_ratio = VOLUME / MA(VOLUME,5)`
- `turnover` = 当日换手率
- `CLV = (CLOSE-LOW)/(HIGH-LOW)`（分母为 0 时取 0.5）
- `breadth` = 当日上涨家数 / 有效报价家数（股票池内）
- `limit_up` = 触及涨停价（用未复权价）

**闸门（全部满足才可交易）：**

```text
NOT ST
AND NOT limit_up
AND price >= 10
AND r1 >= 0.02 AND r1 < 0.05
AND vol_ratio >= 1.5
AND turnover >= 0.03 AND turnover < 0.08
AND CLV >= 0.55
AND (HIGH - CLOSE) / REF(CLOSE,1) < 0.043
AND breadth >= 0.35
AND CLOSE / REF(CLOSE,5) < 1.15          # 五日过热帽
```

**排序（闸门后）：**

```text
score = 2.0*r1 + 1.2*vol_ratio + 0.8*CLV
每日只保留 score 最大的 1 只（并列按代码稳定裁决）
```

**成交与出场：**

```text
T 日：14:50 后确认信号，按未复权收盘价理想化买入（一字/笼子买不进则跳过）
T+1：最高价触及买入价 +3.5% → 止盈
      最低价触及买入价 -6%  → 止损（同日先止损）
      否则 T+1 收盘卖出
持有期 = 1 个可卖日；不补仓
```

### 3.3 为什么这样凝练（相对「只抬止盈」）

| 设计点 | 来自哪类证据 | 要解决的问题 |
|---|---|---|
| 涨幅甜区 2–5% | 零售八步/抢筹高频共识 | 潜龙突破池偏「形态」，缺「当日强弱窗」 |
| 量比 + 换手中带 | 抢筹/东财 | 点火与可交易性 |
| CLV + 限制上影 | 抢筹源码 | 拒绝冲高回落假强 |
| 宽度 ≥35% | 弱市空仓共识 + 本仓 F2 | 系统性隔夜风险 |
| 五日过热帽 | 防末棒 | 替代盲目收紧换手下限 |
| 合成 score Top1 | 排序战法 | 不用 Top2 稀释隔夜边缘 |
| 次日止盈而非开盘卖 | A 股隔夜为负 | 对齐真实「今买明卖」现金流 |

### 3.4 明确不做

- 不把「次日最高%（REFX）」写进信号（未来函数，仅允许回测研究旁路）。
- 不做无过滤全市场隔夜。
- 不默认每日 2 只（隔夜对照中 Top2 曾显著恶化）。
- 不把券商因子 IC 数字当本袖已验证收益。

## 4. 与潜龙尾盘对照

| 维度 | `qianlong-tail-v1` | 凝练 `loci-weipan-overnight-v0` |
|---|---|---|
| 核心入场 | 潜龙突破形态 + 换手 2–8% | **当日涨幅甜区 + 量比/换手/CLV**（可不依赖潜龙形态） |
| 大盘 | 无宽度闸门 | **breadth≥35%** |
| 排序 | ROC5 Top1 | **2·r1 + 1.2·量比 + 0.8·CLV Top1** |
| 出场 | +3% / -6% / 收盘 | **+3.5% / -6% / 收盘**（同属次日兑现；非开盘卖） |
| 理论锚 | 通达信潜龙结构 | A 股「日间强→隔夜持仓→次日冲高」零售共识 + 隔夜为负约束 |
| 关系 | 线上已有 | **候选平行袖**；应用同一半年窗、逐笔口径与潜龙尾盘/ O1–O5 对照后再谈上线 |

### 4.1 建议你拍板的下一步（仍不自动改代码）

1. 用逐笔口径回测：**旧 V1 / O1 / O2 / O3 / O4 / O5 / 凝练 V0** 同窗同成本。  
2. 主看：**PF、均笔、等权连乘、路径回撤、笔数**。  
3. 若 V0 不能稳定优于旧 V1 与 O3，则只吸收模块（例如只加 M1 涨幅带），不整包替换。
