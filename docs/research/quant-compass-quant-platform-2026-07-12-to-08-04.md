# 量化指南针系列通读与本仓启发

> 阅读范围：公众号“量化指南针”《从0到1，一步一步搭建量化平台》从
> 2026-07-12 至 2026-08-04 的第 1 至第 9 篇。
>
> 研究日期：2026-08-04。本文是只读研究，不修改策略默认参数、数据库或
> 生产代码，也不构成投资建议。

## 结论

这个系列最值得采纳的不是再增加一批 RSI、MACD 或财务阈值，而是把“一个
因子是否有效”变成可重放、可否证的研究问题。对本仓而言，下一步应优先补齐
**横截面因子验证**：未来收益标签、每日 RankIC/ICIR、分组单调性、预声明
的训练/样本外切分和覆盖率审计；任何结论先作为研究 artifact，不进入四个
现有战法的默认规则。

本仓当前工作树已经有强于文章示例的交易回测、组合资金槽位、时点和 run-card
基础；真正的短板是尚无可用的财务事实源，也尚无一条把因子面板接到横截面
统计验证的端到端管线。

## 3. 应采纳的路线

### P0：先修复回测入口，再新增只读因子实验

本次核验中，`tests/backtest` 为 `44 passed, 1 failed`。失败点是
`src/backtest/application/runner.py` 中 `run_backtest()` 向
`prepare_backtest_context()` 传入 `tail_days`，但该公开函数的当前签名不接受
这个参数。此问题修复前，不应把任何新因子实验当作可验证的完整回测结论。

修复后再新增研究专用的因子实验入口，不修改策略默认值。最小输入应为：

```text
factor_id / factor_revision / 参数
股票池快照与 pit_membership 状态
行情与来源 snapshot、market_revision、as_of
执行口径（next_open、next_dip 等）
未来收益 label 定义、持有期、成本与不可成交过滤
```

最小输出应为：

```text
每日有效样本数、覆盖率、缺失/停牌/涨跌停剔除原因
日度 Pearson IC 与 RankIC，均值、标准差、ICIR、正 IC 比例
按日同宇宙等量分组的收益、long-short spread、单调性诊断
滚动窗口、市场状态/年度切片、预声明 train/OOS 结果
相同 run_id 的输入 hash、随机种子、artifact manifest
```

其中 RankIC 必须在每个交易日的**股票横截面**上计算，再聚合日度序列；不能用
一只股票沿时间序列的相关性冒充横截面选股因子。未来收益也不能默认使用
`close(t+n) / close(t)-1`：应与策略实际的 `entry_timing`、成本、停牌和限价
可成交性一致，或者在 run card 中明确这是“纯信号标签”而不是可交易收益。

### P1：财务数据先完成 PIT，再讨论 ROE/偿债指标

对 A8/A9 的正确落地顺序是：

1. 只接入可回放的原始事实，至少含 `report_period`、`published_at`、
   `available_at`、`source_url`、`revision/restated` 和原始字段；
2. 用 `PointInTimeObservation` 选择截至回测日已可见的最近值，不允许按报告
   期末或今天的数据回填；
3. 保留年报/季报/半年报的频率与质量标签，重述后生成新 revision，旧 run
   保持可审计；
4. 对 ROE、ROA、利润率、资产负债率等在行业内、同一可见日内做标准化或
   分位处理，再做横截面研究；
5. 数据覆盖不足、历史股票池降级或财报来源失败时，让 run 显式 `blocked` /
   `degraded`，不以当前值填充。

### P2：研究结果只通过门禁进入候选池

建议将“技术/财务因子有效”定义为一个可被拒绝的 hypothesis：预注册宇宙、
时间切分、指标、最低覆盖要求和失败条件，关联一个或多个 `ResearchRunCard`。
只有完整输入、因子统计、OOS、组合回放和人工审阅均合格，才允许它成为一个
新的研究候选；仍不自动改变 `qianlong-close-v3`、`qianlong-tail-v1`、
`rsi30-dip`、`sanyuan-tail-v1` 的规则或资金分配。

## 4. 不应照搬

1. 不把 A7 的简单滚动 RSI 直接替换本仓公式域 RSI。名称相同而平滑算法不同，
   阈值和历史结果不可直接比较。
2. 不把 `volume / avg_volume` 命名为换手率，或以模糊的 `turnover_20d` 覆盖
   已有字段；成交量比、成交额和换手率是不同量纲。
3. 不以单次全样本 IC、单票时间序列 IC、正 IC 天数或几个漂亮分组柱状图宣布
   因子有效；需要日度横截面、分组单调性、时间稳定性、OOS 和同宇宙对照。
4. 不给财务比率写跨行业固定阈值，也不以报告期末代替披露可见日。
5. 不因文章列出多个指标而将其直接拼进生产战法；已有的技术指标应先进入
   只读实验，并接受与现有组合相同的资金占用、空仓和回撤审计。
