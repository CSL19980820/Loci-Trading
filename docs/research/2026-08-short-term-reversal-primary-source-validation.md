# 21 日短期横截面反转一手来源核验

> 核验日：2026-08-05
> 范围：核验短期横截面反转是否值得作为本项目仅用复权 OHLCV 的研究候选。本文件预注册探索口径；不修改策略、默认参数、行情库或生产选股结论。

## 结论

短期反转可以作为一个与 `12-1` 动量方向相反的只读候选来证伪。它有原始期刊论文支撑“短期限个股收益存在可预测的反转/负序列相关”这一研究命题，但该原始美国样本不能直接授权 A 股、T+1 开盘、涨跌停、有限 20 席位或当前行情库中的真实净收益。

因此预注册为：仅检查过去 21 个交易日收益较低的股票，是否在后续 21 个交易日的固定资本账户中优于高过去收益端。若 RankIC、十分位方向、账户收益、PF 和回撤不能共同支持，立刻否决，不把失败结果事后改成追涨动量或换窗口筛最好看的数字。

## 一手来源

### Jegadeesh（1990）

Narasimhan Jegadeesh，*Evidence of Predictable Behavior of Security Returns*，*The Journal of Finance* 45(3), 881--898 (1990)。[DOI](https://doi.org/10.1111/j.1540-6261.1990.tb05110.x)；[Crossref 原始期刊登记](https://api.crossref.org/works/10.1111/j.1540-6261.1990.tb05110.x)。

- 这是原始期刊论文，研究个股收益在不同短期区间的可预测性，而不是后来的博客或策略教程。
- 它支持把短期收益反转作为可被证伪的横截面研究命题；不支持把任何一个固定交易日窗口、只做多端或本项目的成本/执行代理称为论文复现。
- 本轮已通过 Crossref 官方 API 核对标题、DOI、出版方 Wiley 与出版时间（1990-07）；Wiley 页面受反爬保护，未把无法读取的网页摘要伪装成已核验的原文细节。

## 预注册口径

日频工程代理使用同一复权价格：

```text
REV21[i, T] = adjusted_close[i, T] / adjusted_close[i, T-21] - 1
```

`REV21` 越低，代表近 21 个交易日跌幅越大；首轮固定检验“低 `REV21` 优先”。该式只使用形成日 `T` 收盘后可得的信息，T+1 执行，避免把未来价格写回形成日。

| 项目 | 固定口径 |
| --- | --- |
| 形成 | 21 个交易日复权累计收益，不跳过最近交易日 |
| 横截面 | 低/高十分位完整报告；低收益端最多 20 席位 |
| 调仓与持有 | 每 21 个交易日形成，持有 21 个交易日 |
| 执行 | T+1 开盘；入场日停牌或一字板跳过，不以弱票补位 |
| 退出 | 形成后第 21 个交易日收盘；不可交易最多顺延 20 个交易日 |
| 成本 | 往返固定 `0.26%` |
| 账户 | 固定 20 个等权资本槽位，空槽为现金 |
| 比较 | 低/高十分位、RankIC、Top20 账户和年度分段 |

## A 股与 PIT 门禁

1. 当前 `normal` 股票池会产生幸存者偏差；结论不能升级为严格 PIT，直到引入可见日期、历史成分、退市和 ST 快照。
2. 本地库当前 `source_route_receipts=0`、`source_route_attempts=0`，不能宣称行情来源和可见时点可审计。
3. 涨跌停、停牌和不能成交必须按实际可交易性过滤；当前仅使用无停牌、非一字板的开高低收量代理，不能假装有精确涨跌停字段。
4. 即使方向为正，也必须与 PTH252、RSI 低吸和活动趋势策略做冻结样本外增量检查；没有增量时维持现金。

在这些门禁满足前，允许的表述只有：“21 日短期反转是有原始论文支撑、正在用本项目既定执行代理证伪的研究候选。”
