# 龙空龙 / 打板接力体系：术语溯源与「打板 vs 龙回头」拆分论证

> 研究日：2026-08-11。范围：中文交易社群对「龙空龙」「打板接力」「龙回头」的公开用法，以及二者是否应共用一个观测池与一套参数。
>
> **证据等级声明。** 本文所引几乎全部为**中文交易社群自媒体**（东方财富财富号、淘股吧、拾荒网、开普饭、雪球、知乎、股票复盘网等），**不是**交易所规则、监管定义或同行评议研究。本轮**没有**发现任何交易所 / 证监会 / 学术文献为「龙空龙」「龙回头」「打板接力」给出统一可执行定义。凡数值阈值均属民间经验口径，必须当作**待证伪的工程假设**，不得写成已验证结论。制度层面的可成交性约束（涨跌幅、停牌、集合竞价撤单规则）另见 [`dragon-leader-identification.md`](dragon-leader-identification.md) 与 [`2026-08-dragon-king-suite-external-evidence.md`](2026-08-dragon-king-suite-external-evidence.md) 中引用的一手规则。

## 0. 结论先行（含对提问前提的修正）

1. **「龙空龙」不是打板策略，而是仓位/周期闸门。** 主流用法压倒性地是「龙-空-龙」＝*有龙头就做龙头，没有龙头就空仓，空仓等下一个龙头*。其中的「空」是**空仓**，不是「空间」，也不是「龙头空出位置」。有专文逐字解释这个「空」字即空仓（[股票复盘网](https://www.fupanwang.com/zhishi/7690.html)）。
2. **提问中「龙头空间板之后的接力龙」「龙一空出位置给龙二」两种解释，本轮未找到任何可靠来源支持。** 存在一种少数派用法把「龙空龙」讲成*老龙退位 → 模糊窗口期 → 新龙登基*的龙头更替节奏（[55188 论坛帖](https://www.55188.com/thread-16696102-1-1.html)），它接近提问的第二种猜测，但即使在该帖中，落地动作依然是**「模糊窗口期空仓等待」**——仍是闸门，不是接力买法。
3. **因此本仓现状在命名上是对的：** `market_regime.py` 把龙空龙实现成 `dragon / observe / empty` 三态市场闸门（`entry_gate: dragon_empty_dragon`），与主流口径一致，不需要改名，也不应把它改造成一个选股池。
4. **但提问的底层直觉是对的，只是主语放错了。** 真正需要拆分的不是「龙空龙 vs 龙回头」，而是 **「打板 / 接力（追强、盘中实时、右侧）」 vs 「龙回头（低吸、盘后埋伏、逆向）」**。这两者的扫描时点、数据频率、候选生成时间、胜率赔率结构、情绪周期适用段**全部不同**，共用一个观测池和一套参数在工程上不成立（详见 §3、§5）。
5. **龙空龙闸门应当被两个池**共享**，而不是被拆走。** 它回答的是「现在允不允许新增风险」，对打板池和低吸池都适用，只是**阈值档位不同**：打板池要求更严（需要进攻窗），低吸池在观察窗仍可埋伏。
6. 与 2026-08-10 那份《龙王战法体：外部证据与产品边界》**不冲突**：那份讲的是「龙头身份 / 龙空龙 / 龙回头」三层检查应挂在**同一条候选记录**上，避免同一只票分裂成多个名单；本文讲的是**打板与低吸是两类不同的候选生成器**，各自产出的记录再各自走三层检查。一个是"同一只票别拆成多条"，一个是"两类票别塞进一个生成器"。

### (b) 我方建议采用的定义

> **龙空龙（dragon-empty-dragon）＝市场级仓位闸门。**
> 判断「当前是否存在值得全力参与的市场级龙头」，输出三态：
> - `dragon`（进攻窗）：允许新增风险；
> - `observe`（观察窗）：不新增打板类风险，低吸类可小仓试错；
> - `empty`（空仓窗）：不新增任何风险，只维护已有持仓与观察记录。
>
> **它不产出个股候选，也不决定买入方式。** 它是打板池与低吸池**共享**的前置开关。数据缺失时 fail-closed（按空仓处理）。

理由：这是唯一有多来源支撑、且能落成确定性代码的口径；本仓 `evaluate_market_gate()` 已经是这个形态，改动成本为零。**建议同时在 SKILL.md 与 README 里补一句字义澄清**（「空＝空仓，非空间」），防止后续 Agent 或用户再次望文生义。

### 3.3 进场方式（四选一，社群标准分类）

| 方式 | 定义 | 优点 | 缺点 |
|---|---|---|---|
| 打板 | 刚打板或即将打板、剩最后一档挂单时买 | 确定性最高 | 炸板风险 |
| 半路 | 分时开始向上进攻、尚未涨停时买 | 成本低于打板 | **四种里最难**，易买在分时最高点 |
| 低吸 | 分时调整后刚拐头向上时买 | 位置低、错了亏损小 | 对未来确定性最低 |
| 竞价 | 9:25 集合竞价直接买 | 不受分时波动干扰心态 | 无法盘中随机应变 |

来源：[拾荒网·低位二板四种买入方式](http://www.10huang.cn/zhangting/48156_all.html)、[开普饭](https://www.kpfans.com/article/XRvkYgqgWB.html)。手法与行情阶段的配对（初期打板 / 中期接力 / 调整期低吸 / 震荡期半路）见 [东方财富财富号](https://caifuhao.eastmoney.com/news/20250828200736831635260)，属个别说法。

### 3.4 持股周期

- 打板/接力的**默认周期就是隔夜**：A 股 T+1，次日溢价即隔夜收益，「打板的票第二天开盘不及预期，竞价就走，十次中九次正确」（[文学城·心法第 61 条](https://www.wenxuecity.com/blog/202507/55691/2657.html)，个别说法但被广泛转述）。
- 若能连板则继续持有，直到断板或大分歧；「当日不板至少减仓，剩余次日不反包清仓」（同上）。
- 因此**打板持仓的生命周期以「日」计、决策以「分钟/秒」计**；这与龙回头「潜伏 3–10 天等第二波」有量级差异。

## 4. 打板接力 vs 龙回头低吸：对比表

| # | 维度 | 打板 / 接力 | 龙回头 低吸 |
|---|---|---|---|
| 1 | **扫描时点** | 盘中连续扫描；竞价段（9:15–9:25）、封板瞬间、尾盘三个决策窗 | **盘后**（收盘后生成次日候选）；次日只做门闩复核 |
| 2 | **数据频率** | 分钟级至 Tick / 逐笔（封单队列、撤单、吃单需要 L2） | 日 K 为主 + 少量分时确认；日频足够 |
| 3 | **候选池生成时间** | **当日实时生成**，候选在盘中不断新增/淘汰；生成即需决策 | **前一日收盘后生成**，池子跨日存续（可跟踪 T+10） |
| 4 | **信号方向** | 右侧追强：越强越买（封板确认后买） | 左侧/半右侧逆向：等回撤、等缩量、等企稳才买 |
| 5 | **决策依据** | 封单额、封成比、开板次数、首封时间、竞价委买、板块跟风数 | 回撤幅度/天数、缩量比、均线支撑、二次启动放量阳线 |
| 6 | **胜率 / 赔率结构** | 低胜率（无差别 40%–50%，晋级 10%–30%）+ 厚尾大赔率；靠少数连板 | 自称高胜率、目标收益 10%–25% 的有限赔率；「能走大二波的只在少数」 |
| 7 | **持股周期** | T+1 为默认；不及预期竞价就走；能连板则续 | 3–10 个交易日的埋伏窗；第二波拉升遇压力分批止盈 |
| 8 | **情绪周期依赖** | **强依赖**：主升/高潮期才有效，退潮期容错率极低，冰点期几乎不可做 | **中等依赖**：分歧/回调期是主场；市场人气越高概率越大，但退潮期同样应回避 |
| 9 | **失效判定** | 炸板、封单萎缩、次日竞价不及预期 → 当日/次日即离场 | 跌破回调低点 / 跌破 20 日线 3 日不收回 / 回撤 >30% |
| 10 | **可自动化程度** | 提醒可自动化，**成交不可保证**（涨停价限价单可能买不到最强、只买到烂板） | 候选生成可完全自动化；次日开盘执行滑点相对可控 |
| 11 | **参数对象** | 盘口微观量（封单、开板、时间戳、竞价额） | 形态与统计量（回撤%、天数、缩量、均线距离） |
| 12 | **对数据源的要求** | 需要秒级刷新与逐笔封单变化；快照延迟直接导致信号作废 | 日终快照即可；对延迟不敏感 |

### 为什么不能共用一个观测池 / 一套参数

1. **候选生成时间不同 → 池子的「当前事实」语义不同。** 低吸池的一条记录在盘后就已冻结，次日只做复核；打板池的一条记录在盘中每分钟都可能新增或作废。塞进一个池，用户永远不知道看到的这一行是「昨晚定的」还是「刚刚出的」。
2. **数据频率不同 → 刷新与配额策略不同。** 打板池需要秒级/分钟级刷新，低吸池日终一次即可。共用会导致要么低吸池被无意义地高频重算，要么打板池被日频拖成过期信号。
3. **信号方向相反 → 同一个「强度」字段含义相反。** 打板池里「今日涨停 + 封单巨大」是**加分**；低吸池里「今日已涨停无回撤」恰恰是**未进入买点**（本仓 `_buy_zone_status()` 明确要求 `pullback_days >= 1`，「尚未回撤」直接判否）。同一字段两套符号，一套参数不可能同时正确。
4. **胜率赔率结构不同 → 仓位与止损规则不可共享。** 厚尾低胜率策略需要小仓多次 + 快速止损；高胜率有限赔率策略需要更大单笔仓位 + 更宽容错。共用 `candidate_score` / `max_candidates` 会把两种风险预算搅在一起。
5. **情绪周期适用段不同 → 闸门档位不同。** 见 §5：退潮期打板必须硬关，而低吸池此时仍可保留观察与埋伏候选。共用一个 `entry_allowed` 布尔量，只能二选一地牺牲一方。

## 6. 打板 / 接力观测池规则草案

> 定位：**扫描 + 提醒**，不自动下单。所有输出标注 `validation: unverified`，与本仓现有纸面舱口径一致。

### 6.1 实时字段清单

| 类别 | 字段 | 必需性 | 悟道 MCP 可得性 |
|---|---|---|---|
| 身份 | code、name、题材归属、连板层级 `ladder_level` | 必需 | `limit_up_ladder` / `theme_stocks` |
| 封板 | 首次封板时间、最终封板时间、开板次数、当前封单额、封单额变化率 | 必需 | `limit_up_ladder`（含 `firstLimitUpTimeText` / `lastLimitUpTimeText`）、`auction_market_scan`（`finalSealAmount`） |
| 封板质量 | 封成比（封单/成交额）、封流比（封单/流通市值）、板上成交占比 | 建议 | 需自算；封单与成交额可得 |
| 竞价 | 竞价涨幅、竞价成交额、涨停委买额（`limitBuyAmount`）、9:20 后委买（`limitBuyAmountAfter920`） | 必需 | `auction_market_scan` / `auction_opening_snapshot` |
| 板块 | 同题材当日涨停家数、封死到收盘家数、题材盘中强度与资金 | 必需 | `theme_intraday_capital` / `theme_stocks` |
| 情绪 | 涨停家数、最高连板高度、炸板率、晋级率、昨日涨停今日表现、跌停家数 | 必需 | `short_term_emotion` / `limit_stats` |
| 风险 | 是否 ST、是否停牌、是否一字板（不可成交）、近期减持/监管公告 | 必需 | `stock_screener` / `official_announcements` |

**两个必须写进实现的陷阱：**
1. 「封板时间」多数数据源给的是**最后一次**封板时间，而决策要用**第一次**（[来源](http://cnnetsun.cn/a/3920235)）。字段名必须区分，不能混用。
2. 显示的封单额包含**挂出即撤的虚假挂单**（同上）。没有逐笔数据时，应把封单额降级为「参考量」，并用「封单额变化率」而非绝对值做提醒。

### 6.2 刷新频率

| 时段 | 频率 | 理由 |
|---|---|---|
| 9:15–9:20 | 不采信（可撤单段） | 多来源共识：此段虚假挂单为主 |
| 9:20–9:25 | 30 秒 | 不可撤单，数据真实，是竞价决策唯一有效窗 |
| 9:25–9:30 | 一次全量快照 | 锁定竞价结论，生成开盘观察名单 |
| 9:30–11:30 / 13:00–14:30 | 60 秒（候选内个股 30 秒） | 商用打板工具可达秒级（[测评](http://www.investorscn.com/2026/03/05/127517/)），但本仓走 MCP 配额，60 秒是配额与时效的折中 |
| 14:30–15:00 | 30 秒 | 尾盘封板质量与次日预案 |
| 收盘后 | 一次 | 复盘 + 生成次日观察，交棒给低吸池 |

**配额约束提醒：** 悟道免费额度在 09:15–10:30 暂停服务，这恰好覆盖竞价与早盘主战场。**打板池若走免费额度，等于在最关键的时段无数据**——这是拆分方案必须先解决的前置问题，否则打板池只能做成「10:30 后的盘中接力池 + 尾盘池」。

### 6.3 触发提醒的条件（分级）

**L1 · 池准入（不提醒，只入池）**
- 龙空龙闸门 = `dragon`（打板池要求进攻窗，不接受观察窗）；
- 且同题材当日涨停 ≥3 家；
- 且非 ST / 未停牌 / 非一字板（一字板不可成交，只做观察不提醒）。

**L2 · 关注提醒（推送，低优先级）**
- 竞价段：竞价成交额 >800 万 且 竞价涨幅 >3% 且 9:20 后委买持续增加；
- 或盘中：题材内**首个**封板个股出现（时间优先＝龙一候选）；
- 或：连板梯队出现新的最高板。

**L3 · 决策提醒（推送，高优先级）**
- 封板 **且** 开板次数 ≤1 **且** 首次封板时间 <11:00 **且** 封成比进入当日前 20% **且** 同题材封死家数 ≥2；
- 或弱转强：昨日为断板/烂板/尾盘炸板，今日竞价高开且量能放大后快速封板；
- 或断板反包：≥2 连板后断板（断板日收盘未跌停、K 线小阴小阳、量能未显著放大），次日带量上攻。

**L4 · 风险提醒（推送，最高优先级，持仓相关）**
- 封单额较峰值萎缩 >50%（炸板预警）；
- 或已炸板未回封超过 10 分钟；
- 或市场级：最高板核按钮 / 炸板率突破 45% / 连板溢价率转负 → **全池降级为空仓窗，停止一切 L2/L3 提醒**。

**否决项（任一命中即不提醒）**
- 一字板（买不到）；
- 缩量新高板次日接力（[ViTa 三不做](https://www.tgb.cn/a/2pWF7Q5SpDu)）；
- 情绪高潮次日或退潮期的秒板票、中位板、新题材（同上）；
- 「有高不做低」：最高板仍在连板时的低位卡位连板（同上）；
- 板块「独苗」涨停（无跟风）。

### 6.4 输出契约

每条提醒必须同时给出三层理由，与现有 `suite_checks` 结构对齐：

```text
XX科技 | L3 决策提醒 | 10:32
龙空龙：进攻窗（晋级率 0.42 / 炸板率 0.26 / 高度 5 板）
接力身份：AI 算力题材龙二，题材今日 6 板 3 封死
封板质量：10:18 首封、0 次开板、封成比 18%、封单 2.3 亿（含虚挂，仅供参考）
否决检查：非一字 / 非缩量新高 / 非中位板 → 通过
validation: unverified · 本提醒不构成买卖建议
```

### 6.5 与低吸池的交接

- **打板池 → 低吸池：** 打板池中断板但未跌停、且仍具辨识度（≥2 连板）的票，收盘后自动转入低吸池的「反包/回头观察」，保留原有 `T` 锚点与连板历史。
- **低吸池 → 打板池：** 低吸池中的票若在盘中出现弱转强快速封板，可临时升级为打板池 L3 候选，但**必须重新过龙空龙进攻窗检查**。
- **两池共享**：龙空龙闸门快照、题材强度快照、股票基础信息与风险字段（避免重复扣配额）。
- **两池不共享**：候选生成器、评分函数、参数段、刷新节奏、提醒分级。
