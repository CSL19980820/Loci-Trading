# 两形态的有限净收益学习排序

2026-10-04。前一轮手工结构、风险预算和环境规则未证明增强。本轮检验一个不同机制：用完整候选池的已成熟订单机会收益学习排序，是否优于各自原评分。仅隔离研究，正式策略、生产任务和账户不变。

## 预先固定的模型与目标

每种形态各自一个线性ridge模型，至多12个事先确定的因果特征。模型共享数学实现，不共享训练样本或系数，也不照搬另一形态的评分权重。

目标为每次预定下单机会扣除0.21%往返成本后的净收益，单位为百分点。已平仓交易使用真实退出日已知的净收益；有明确涨停开盘或有限非正成交量等证据、确定不能成交的订单记0，标签直到取消当日才可用。无效/缺失报价、未知限价参考、已成交未平仓都是未知，不填0，不把它们当确定亏盈标签。全部候选保留状态和原因。

训练仅使用当时已经知道的标签和有限特征。每个可用训练决策日的样本权重总和相同，再归一化使全样本权重和为1；没有候选的日期不人为新增训练零标签。优化目标精确为：

`sum(w_i * (y_i - intercept - z_i @ beta)^2) + 1.0 * sum(beta^2)`

只拟合一个固定λ=1.0，无网格、交叉验证选λ、特征组合搜索或目标剪裁。特征均值与标准差只由训练样本按上述权重估计；标准化后固定截到[-5,5]，再对截断后的设计重新加权中心化，截距不受惩罚。常量列标准差记1。缺失特征不插补，模型不对该行评分，同时保留相同特征资格的原评分对照。

ridge的平方残差与系数惩罚定义参见[官方Ridge文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。本文明确使用总和为1的日期权重，因此λ数值不能与未归一化残差和的其他实现直接比较。股票收益学习的既有研究使用不同市场、频率和信息集合；[Gu、Kelly与Xiu](https://www.nber.org/papers/w25398)不能作为本项目A股四日形态具有收益的证明。

## 各自的固定特征

倍量阴在T开盘代理决策，T是阴线后的下一市场日：

1. T−2强阳涨幅；截至T−2近10日涨幅。
2. T−1/T−2量比；阴线实体跌幅；阴线收盘位置；阴线收盘保留前阳实体比例。
3. T经济开盘缺口；T开盘在前60日高低区间的位置；T开盘距前MA5/10/20的最小相对距离。
4. T−1沪深30020日回报；T−1有效主板MA20宽度；T−1有效主板上涨比例。

二次突破在T收盘决策、T+1开盘代理执行：

1. 10日动量；距最近合格强阳的市场日数；两日回调深度。
2. 两回调日成交量/各自MA5量的平均；突破日/前日量比。
3. 收盘超过前5日最高点的幅度；收盘位置；阳实体/当日振幅；当日振幅/此前14日ATR；收盘到两回调日最低价的距离。
4. 截至T沪深30020日回报；截至T有效创业板MA20宽度。

宽度使用相应全板块STOCK股票，至少20个连续市场日有限正收盘且成交量为正；不能用未来上市样本增加当时分母。不以形态候选、当下ST名称进一步缩小宽度分母。倍量阴不用T日最终高低收量；二次突破不用次日开盘缺口。各适配器在冻结计划中列出精确公式。

股票信号几何使用数据库直读权益因子及统一稳定精度，执行仍是原价×真实因子。完整校正形态池必须从原条件重组，不能只修改旧Top2或对旧候选取交集。当前目录、行业及因子修订偏差继续披露。

## 只比较两种使用方式

- `rank_only`：在特征完整候选池按预测净收益取每日最多两只。
- `positive_only`：先要求预测净收益>0，再按同样方式取每日最多两只，可以为空。

两者都将预测值保留到小数后10位再比较，使用有符号值，不裁成0～100分；分数相同按代码升序。倍量阴保留完整行业组交集去重，二次突破保留其原行业合同。先预选、后判成交，取消不补位。预测候选资格不得读取标签是否已知、未来能否成交或最终盈亏。

退出固定沿用包含入场日4个市场日及−6%止损、T+1、跳空及不可卖日顺延。这里比较的是排序和是否出手，不加入新的形态门槛、退出、持仓去重或冷却。原始事件模型和真实共享资金模型分开。

对照包括原行为、技术校正全池原评分、与模型相同特征资格的原评分。倍量阴另保留校正后的原低开控制，完整形态不强制低开。学习增益须与这些技术/资格变化分开，不能将纠错和删样本都记到模型头上。

## 时间顺序、提名和停止条件

1. **内部拟合：2024。** 只读到2024-12-31。每条训练标签须有`label_available_date`，实际退出或已知取消不晚于该日且早于验证开始；延迟未决不进入拟合。训练至少100条有效标签、60个决策日、6个月。这是12特征学习所需的最低信息量，不是提高交易频率的门槛。
2. **内部验证：2025上半年。** 保持2024模型固定，对两个预定政策各自执行；同时跑对应对照。至少20笔已平仓、3个活跃月，净均值>0、PF>1，双成本且删除最大赢家后仍正；共同日历名额均值须高于技术校正全池、同资格原分和原行为对照。被选中的未知/未决订单使该段不可提名。两政策最多都可入围；无人合格即停止本学习家族，不改λ、特征、阈值或退出。
3. **全训练重拟合：2024至2025上半年。** 仅在内部验证有合格政策时执行；数学与特征不变，只加入截至2025-06-30已成熟的训练标签。不得据此更换未入围政策。
4. **已观察后段：2025下半年、2026年1至9月。** 仅运行冻结入围政策及对照，两个阶段使用同一个全训练模型。每段至少12笔、4个活跃月，均值>0、PF>1，共同名额贡献均高于各相应对照；合计至少40笔，双费用、删除最大赢家及二者叠加后均为正。月块配对区间照实公布，区间跨0不称为统计确认的优势。
5. **同资金验证。** 只有通过上述关卡的候选才使用此前冻结的固定总资金约束，与对应基线比较收益及日收盘回撤。模型的多笔独立交易不能直接称为账户收益。2023H2继续保留，不因本轮失败而另找该时段的好结果。

评估主分母是各阶段共同计划成熟的全部市场决策日×2，包括没有信号、过滤和未成交的日期。训练实际标签可用性与评估共同成熟窗口分别记录，不能混用两种分母。未平仓保留未知，不从收益账本消失。

## 验证与实际目标

核心自检检查未来标签/特征不影响过去拟合、日期权重、单位尺度、过去标准化、截断后的截距和取消标签时点；适配器另查完整候选池、信号时点、标签成熟、先排序后成交、对照一致及费用/原名额守恒。所有源、快照和计划冻结后再跑新结果。

这仍是对已经多次观察的历史开展有限开发，不能称为全新样本外。训练内按时间留出是本轮进一步约束，不能清除前轮研究已形成的选择偏差。目标仍是两策略的扣费后收益增强，模型能够运行、拟合误差降低、信号变少或研究完成都不能代替这个目标。
