# 两策略后续资料可用性核验

核验日期：2026-10-04。范围为现有行情快照、项目数据契约，以及生产行情库/归档的结构、日期、行数和代码覆盖。生产查询使用 SQLite `mode=ro`、`query_only=ON` 与一致读事务；归档只读明文 manifest，未读取密钥或解密文件。本轮未访问账户、写库、调用新行情取数、批量下载、创建采集任务或运行收益实验。

## 判断

**日线资料并未用尽。** 现有快照可以立即导出成交额；也保存了按交易日排列的流通股本与换手率，其中有历史股本变动来源，不能简单说“只有现在的流通盘”。这三项并未进入本轮十二特征学习模型。但成交额有效、换手有值和严格的历史时点可得性，是三个不同层次；它们尚不证明新的盈利能力。

**现有系统没有已核验完整覆盖 2024–2026 的两策略候选竞价、分钟 OHLCV、逐档订单簿或历史行业成员版本。** 生产已有近期竞价、分钟和题材缓存，属于可用的近期局部证据；其长度、覆盖或截断状态不足以支撑这两策略三年的完整候选对照。此结论没有宣称所有日 K 均无信息，也没有宣称外部供应商一定没有历史资料。

### 历史时点限制

- 快照中的 `instruments` 是当前证券目录，5,570 只股票只有 2,902 只带 `industry`，更新时刻均为 2026-10-02；没有按有效起止日保存行业、名称/ST、退市状态的版本表。存在上市日期字段不等于历史证券目录已完整。
- 本轮研究用的 [candidate-industry-groups.json](../../../.local/multi-strategy-scoring-20261004/candidate-industry-groups.json) 来自 `eastmoney_orginfo`，抓取于 2026-10-04；早期 [industry-mapping.json](../../../.local/multi-strategy-scoring-20261004/industry-mapping.json) 仅是 2026-09-30 的十个代码映射。这些都不是 2024–2026 每日有效行业成员库。
- 2024–2026 日线的 `fetched_at` 是 2026-08-24 至 2026-10-02 的补采/更新时刻。快照中 49,644 条日线回执的 `available_at` 全为空。**晚抓取不表示历史价格当年不可知**，但只能证明当前重建版本，不能证明供应商在当时已发布同一修订值。
- 日线可以由多源互补；行级 `source` 是主源，不能替代每个字段的来源和发布日期。当前 schema 没有保留股本每个值是原生、前向填充还是反推的字段级标记。因此成交额可以进入现有历史研究框架，历史换手/流通盘则需要先明确允许的估算口径；若要求严格 PIT，还缺版本和可用时间证据。

## 定向核验：成交额 / 股数能否表示日成交均价

按追加的只读任务，仅检查两策略**已经生成的候选代码/日期**及其前一市场日，没有使用是否入选、成交、盈亏或未来标签筛样。候选 CSV 虽有其他列，本步骤只取 `decision_date`/`signal_date` 和 `code`。数据仍来自同一冻结数据库。

- 倍量阴：完整形态候选，训练重拟合候选 1,301 条、2025H2 459 条、2026 757 条，去重后 **2,517 个候选事件**，2024-01-02 至 2026-09-24。输入为 `refit_full_train-candidate-labels.csv`、`validation_2025h2-predictions-and-selection.csv`、`observed_2026-predictions-and-selection.csv`，位于 `docs/research/2026-10-04-double-yin-learned-rank/`。
- 二次突破：既存原完整形态候选账本，训练 430 条、2025H2 184 条、2026 311 条，共 **925 个事件**，2024-01-05 至 2026-09-23。输入是 `docs/research/2026-10-04-multi-strategy-scoring/contraction-rebreakout-v1/` 下三段 `*-candidates.csv`；不是只取原 Top2。此处未生成本轮停止后新的后段学习候选。

`tdx_daily._rows_to_frame` 明确将源侧 `vol` 的“手”乘 100 转为仓内“股”，`amount` 原本就是元；因此仓内同日 `amount/volume` 的单位是元/股。**对仓内 volume 不应再乘 100。** 检查要求 amount、volume、原价 high/low 均为有限正值且 high≥low；使用 `low−0.01 ≤ amount/volume ≤ high+0.01`（另仅加浮点 epsilon），容差为一分钱。又分别试算 volume×100 与 volume÷100 的量纲假设，只统计一致性，不修改数据。

## 已有接口能力与实际缺口

1. **历史分钟接口已经有。** `DataAdapter.fetch_minute(code, trade_date=...)`、[TDX 读取](../../../src/market/infrastructure/tdx_minute.py) 和新浪读取是现成入口，不需要从零造适配器。但当前 TDX 实现只有 `datetime/close/volume`，要求 240 点，时间标签由固定交易时段补齐；没有源生分钟开高低或金额。接口接受历史日期不证明供应商覆盖每个 2024–2026 候选，且该调用不自动保存历史库。本轮没有再打网络探针。
2. **竞价供应商入口已经有。** [Wudao tape provider](../../../src/market/infrastructure/tape/wudao_provider.py) 对接 `auction_opening_snapshot`，支持规范交易日参数；本地日线降级明确不提供竞价等价物。若要恢复长历史，首先需要供应商按日期返回范围、分页/截断、当时生成时间和字段完整性的覆盖证明。现有缓存只能证明上表中的近期局部数据已经拿到。
3. **订单簿缺的是历史事实。** 已核验库没有订单簿表，归档清单没有买卖档位字段；竞价统计不能还原盘口队列、逐档深度、撤单、部分成交和真实委托执行。需要外部既存历史 L1/L2/逐笔数据的可授权导出或新的前向留存；前向留存无法补出过去三年的证据。本轮未启动任何采集。
4. **行业 PIT 缺的是成员版本。** 当前行业映射和最近一个月题材缓存不能代替含 `effective_from/effective_to`、发布时间/可用时间、历史成员与退市/ST 状态的数据集。完整历史行业比较需要供应商既存的变更历史/版本快照；当前映射仍可用于明确标注非 PIT 的描述或既有代理研究。
5. **还有一份既存局部时点资料，但不属于本研究完整池。** 同日已核验的 [盘中可行性材料](../2026-10-04-chinext-payoff-study/intraday-feasibility.md) 记录另一策略 `impulse-pullback-tail-v1` 的 2025–2026 14:50 数据集：8,272 行、408 个日期、2,094 个代码，每日 1–63 行。这是另一策略事前候选子集，不能换名用于倍量阴或二次突破全池。此处复用既有核验记录，没有扩大本轮生产读取至租户或账户资料。

## 对后续工作的含义

**当前不被数据阻塞的部分**是从冻结快照导出已有成交额和明确口径的日度额外字段，或检查近期缓存的特定历史片段。它们“已有但本轮未用”，不能因为手工/单一 ridge 家族失败就推断无价值；也不能在没有新冻结目标和验证边界时继续择参。

**真正需要外部补足的部分**是：覆盖目标日期及完整可能候选范围的历史竞价/分钟/盘口资料，以及行业、股本公告和证券状态的历史有效版本。所需不是另一个声称支持日期参数的接口名称，而是可核验的覆盖清单、原始字段/单位、时间语义、缺失与分页说明、修订/发布时间和授权导出。现有稀疏缓存无法代替这些证据。
