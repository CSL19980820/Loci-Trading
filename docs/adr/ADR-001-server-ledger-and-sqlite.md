# ADR-001：服务器单一事实账本与 SQLite

**状态**：已废止（2026-07-28）  
**日期**：2026-07-24

## 废止说明

公网服务器部署（`qianlong.chenkit.cloud`、`/srv/qianlong-palace`、Docker Compose、
`scripts/sync-to-server.ps1`、`deploy/`、`docs/deployment.md`）已全部下线并拆除。
产品改为本机桌面便携版（`Loci.exe` / 本地 FastAPI），账本事实源为本机 `data/` 目录。

下文仅保留历史决策记录，不再作为运行规范。

## 背景（历史）

潜龙记忆宫殿需要长期保存候选、预案、成交、复盘与规则样本。主要写入者是 Agent 和单个工作台，而不是高并发多用户系统；当时希望部署后不再依赖本机长期运行，并在日后“同步”时更新服务。

## 方案对比（历史）

| 方案 | 运行复杂度 | 账本一致性 | 适配当时规模 | 结论 |
|---|---:|---:|---:|---|
| 服务器单实例 + SQLite/WAL | 低 | 强（单文件事务） | 高 | 曾采用 |
| 本地与服务器双向同步 SQLite 文件 | 中 | 弱（易覆盖、冲突） | 低 | 不采用 |
| PostgreSQL + 多服务/多副本 | 高 | 强 | 当时过度 | 未采用 |

## 决策（历史）

服务器 `/srv/qianlong-palace/data/palace.db` 曾是唯一事实源；FastAPI 单实例挂载该目录并使用 SQLite WAL。

## 后果（历史）

- 优点：部署成本低、事务审计完整、备份和迁移简单。
- 约束：服务保持单副本；SQLite 文件不能作为跨设备同步介质。
