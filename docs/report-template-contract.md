# Stock Analyzer 定稿报告模板契约

本项目的报告不是临时生成稿，而是固定版本的研究报告模板。程序负责取数、计算和渲染；Codex 负责补充在线核验材料；最终 Markdown、HTML、PDF 必须共享同一套章节顺序和视觉规范。

## 模板版本

- 模板 ID：`stock_research_final_v1`
- 适用输出：Markdown、HTML、PDF
- 固定源模板：`templates/holding_report.md.j2`
- 视觉规范：`docs/report-visual-design.md`
- 在线核验证据格式：`examples/online_evidence.sample.json`

模板 ID 和章节顺序变更时，必须同步更新 README 和样例证据文件。

## 固定章节顺序

1. 封面与报告元信息
2. 数据来源与在线核验状态
3. 持仓现状诊断
4. K 线回看
5. 技术面快照
6. 资金面
7. 基本面与行业面
8. 关键价位与回本概率
9. 买入辅助检查（非买入建议）
10. 风险雷达
11. 持仓组合分析
12. 三档情景观察框架（非交易指令）
13. Codex 在线核验摘要
14. AI 二次分析上下文
15. 风险提示与免责声明

不得在运行时按心情改标题、调顺序或删除章节。没有数据的章节必须显示“未提供/不可用/需核验”，保持版式稳定。

## 程序与 Codex 分工

程序固定输出：

- 行情/K 线/资金流/财务/研报/龙虎榜等结构化数据
- 指标、风险雷达、买入辅助检查、组合分析
- `summary.json`、`ai_context.json`、Markdown、HTML、PDF

Codex 在线补充：

- 官方公告、交易所/巨潮资讯、公司官网、行情网页或其他网页预览核验
- 数据差异说明，例如网页行情与 AkShare 快照是否一致
- 需要人工继续核验的信息
- 重要来源链接和查询时点

Codex 不应直接改模板章节结构，只应把在线核验结果写入证据 JSON，再由程序渲染。

## 合规边界

报告只能输出公开信息整理、风险列举、条件成熟度和情景观察。禁止输出确定性买卖指令、收益承诺、内幕信息推断或个性化荐股结论。
