# 股票智能体中心

入口：我的 → 智能体（`/agents`）。内置天才交易员位于 `/agents/guardian`，使用独立的组件、配置、账户及决策链，不套用新智能体的3/5持仓规则。设置页的 `tab=guardian` 自动跳转。

## 使用

新建股票智能体，或用列表底部的“龙头选手”模板创建。默认暂停，需要选择已经启用的供应商和模型后自行启用。各智能体有独立提示词、初始模拟资金、账户、观察名单、工作日程及历史。参考战法只列当前租户真实存在且启用的工坊战法。

龙头选手模板覆盖1进2、2进3、接力和龙空龙的研究职责。默认北京时间08:50盘前计划、09:25竞价研判、20:00晚间复盘；盘中默认每5分钟。14:50和14:55按已确认的留仓名单执行尾盘收敛，不依赖新一轮模型回答。交易所休市或所需行情不可用时不伪造成交。

09:25只判断是否参与及条件，不按当时尚不可连续成交的报价记模拟成交。盘中执行前重新校验行情、时段、费用、现金、股数和T+1。

每日累计入选最多3只，当前观察最多3只，常态持仓最多3只，临时最多5只；移出观察和卖出不重置当天名额。临时超配须提供可行的收盘留仓名单；新买入导致的T+1锁仓数量不得超过常态上限。模型提示词不能覆盖这些限制。因停牌、涨跌停流动性或报价缺失无法退出时明确记录拒绝原因，不保证机械收敛成功。

## 账户和历史

工作室使用独立栏目导航：桌面放在内容左侧，手机放在标题下方的独立横栏。页面占用浏览器可用高度，长内容在栏目内部滚动。账户内切换完整持仓页和曲线，工作日程由标题按钮打开。“观察名单”显示完整观察池的观察日期、观察价、现价、参与参考价和最近复核；首次入池保存实际取到的观察价，报价失败或旧记录缺价保持未知，后续现价不冒充观察价。“研究计划”桌面按3:1展示接续计划和近期工作，手机上下排列。“工作日记”默认北京时间当天，历史日记在最后一个栏目；累计统计和日期位于同一工具栏。行内仅列实际买卖或未执行意图，观察股在名单和详细报告中查看。成交记录最新在前，大详情使用结构化报告并保留旧原文。

追加资金使用幂等请求号；超时重试沿用同一请求号，防止重复注资。初始资金创建后固定，累计投入通过流水增加。累计盈亏 = 净资产 − 累计投入，追加资金不制造利润。曲线支持当日、近七日、一月、半年和一年；当日使用每轮保存的真实估值，其余使用每日最后快照，不补造旧时点。买入价由本账户真实成交回放，含费成本和盈亏另列。

每次运行具有租约、配置版本和账户版本。运行中暂停、修改配置、追加资金或失去运行所有权后，旧结果不能覆盖账户。模拟成交、资金变动、持仓数量和成交事实在同一事务中校验并提交。

## 存储与保留策略

私有 `palace.db` 新增 `stock_agent_profiles`、`stock_agent_runs`、`stock_agent_trades`、`stock_agent_funding`、`stock_agent_equity`，不与 `guardian_*` 原账本混写。所有查写按当前租户解析，后台运行显式捕获租户身份。模型和工具不得读取其他智能体的账户及日记。

默认保留30天或2000条日记，任一条件超出即可清理；0关闭对应条件，两者都为0关闭自动清理。默认每24小时检查，维护任务每小时触发但按各配置判断是否到期；暂停智能体也能清理。每批最多1000条，保护当天、运行中及最近20次完整日记。累计次数、成交、资金流水和曲线不随日记清理删除。

天才交易员独立使用 `guardian_diary_preferences` 和 `guardian_diary_compactions`：过期的庞大详细上下文压缩为摘要，保留运行槽防止重复执行；当天、运行中和最近40次完整记录不变，财务账本和报告不动。后台维护不改变它的算法或提示词。

清理是逻辑删除/压缩，不自动对线上SQLite执行VACUUM，也不保证数据库文件立即缩小。财务事实持续保留，仍需要正常备份和容量管理。

## 猎隼

“新建股票智能体”中选择猎隼模板。它继承天才交易员已选择的模型，拥有独立模拟账户，默认暂停；选择可用模型并启用后按北京时间08:50、09:25、盘中每5分钟、20:00日复盘和周五20:30周复盘运行。周五休市仍可总结该周已保存的证据，不制造成交。

“更多操作 → 即时研判”可随时开展当前候选研究，使用真实配置的模型，只更新研究和观察，不执行模拟成交，也不把午休或盘外报价当作连续交易价格。正常盘中入口继续遵守交易时段。

猎隼只消费当前租户已产生的量化候选和技能统一监察池；不重新选股、不读取其他智能体账户。量化明确落选可只读研究评分，但不授权新仓；精选、观察及可参与技能候选才允许新增观察、买入或加仓。已有持仓即使不再入池仍可持有、减仓与退出。工具、交易预检和账本提交各自核验候选范围。

策略的买点、分数和开盘建议只是研究依据。猎隼结合市场环境、板块、量价、承接、消息及流动性自主判断参与或退出，允许等待或空仓。环境工具提供已入库日线广度/行业聚合和系统已配置的盘面情绪线路，均不返回新股票榜单；实时来源缺失或陈旧时明确说明。超短是默认研究节奏，保留T+1与实际可成交盘口约束；延长持有须说明仍有效的事实、退出条件和下次复核时点，不承诺事后最高/最低点。

日、周复盘分别分析选择、择时和执行，结构化保存经验与选股/判分优化假设。条目包含证据编号、样本口径、适用条件、正反例、验证计划及待验证/有证据支持/已被否定状态。只允许引用本轮可见证据，实际成交样本须来自本账户已落账流水，拒单和预演不算成交。建议不会自动修改策略、分数或任务。

“经验沉淀”最多12条经验、8条建议，并限制每项文字长度。AI可根据真实证据验证、更新、替换或删除条目，每轮最多8项维护；完整维护前后值保存在日记，账户审计最多64条且不超过128KiB，公开展示只返回有界记忆。每周复盘分页读取该周所有已完成记录和成交，不以最近12轮代替全周。历史补复盘不改今天的观察/执行计划，也不覆盖较新的经验。技能池历史覆盖、原位修改的候选裁决等缺口会明确提示；历史量化只使用截止前已保存的当轮候选快照，缺失快照不重建当时的分数、判分依据或参与资格。

每轮模型实际加载 `templates/agent-workbench/compact-stock-research/SKILL.md`，按模板输出接续计划、简短工作日记和逐股复核；技能名称、版本、SHA256和校验结果保存于usage收据。全池覆盖与重点对象单独记录，未复核对象明确标记，缺报价不生成进场价。下一交易日采用系统交易所日程，修正保留模型原日期，不修改旧日记。

本地验证使用隔离数据库与模型/行情替身，覆盖来源、工具范围、模拟成交、记忆持久化和日程；真实模型效果与生产定时运行需要部署及配置后的运行证据。

## 退役边界

大屏、旧复盘页面、信号规则设置页、体检及其独立组件已移除；旧地址跳转到现存页面。胜率只展示真实启用的工坊战法及当前显示名，旧统计不会把已删除战法重新带回界面。

页面退役不等于删除仍在使用的算法。`signal_rule_config` 仍被实时信号引擎读取；`signal_journal` 仍由行情信号落地、回看等逻辑使用，必须保留。候选跟踪、胜率统计、策略衰减/重叠分析等仍被研究能力使用的基础实现与历史事实不因菜单删除而物理清空。本次没有对线上数据库执行DROP或数据迁移。

## 验证入口及边界

后端测试见 `tests/test_stock_agent_workbench.py`、`tests/test_agent_workbench_skill.py`、`tests/test_falcon_runtime.py`、`tests/test_falcon_learning.py`、`tests/test_falcon_watch_pool.py`，以及候选、来源同步和现有撮合回归。覆盖实际价格与时间、曲线范围、完整动作摘要、模型技能加载、全池覆盖、有限记忆、历史证据、来源关闭和过期清理。

`frontend/e2e/agent-workspace-regression.mjs` 使用隔离只读路由样本验收1440×900、1366×768、1024×600、390×844的总览、左侧栏目导航、长名单、日记分页、完整报告、经验和优化建议；拒绝全部API写请求和外站请求。运行：`node frontend/e2e/agent-workspace-regression.mjs`。`frontend/e2e/falcon-agent-regression.mjs` 另用模拟API验收模板、设置、周复盘与即时研判确认，不创建真实智能体或触发付费调用。脚本自启本地Vite；本机缺少Playwright Chromium时可设置 `PLAYWRIGHT_CHANNEL=msedge` 复用Edge。

这是模拟研究与模拟交易，不连接券商。暂未模拟真实盘口排队、部分成交、分红送转等全部券商行为；新账户不回填创建前的历史收益。模型选股质量、真实行情连接以及线上交易日定时运行仍需要上线后按真实配置验收，不能由替身测试推导为收益保证。
