# 身份认证与账号系统 (Auth & Identity)

Loci 前端身份认证模块提供多态登录/注册流、QR 扫码状态机、当前用户全局 Store 以及账号中心。

## 1. 登录页多态流 (LoginView)

### 1.0 骨架与尺度

`LoginView.vue` 保留登录状态机与布局，五种表单由子组件承载。`LoginLayout.css` 使用满高双栏：品牌侧展示行情、策略、助手、复盘四个模块；表单侧依次为外观切换、表单正文和底部说明。

- 两侧均使用表面、文字和间距令牌，跟随外观设置；登录前不展示未经获取的行情或运行状态。
- 表单列上限 27rem，登录控件高度由局部 `--ctl-h` 按间距令牌派生；不改变工作台密度。五个表单共用 `AuthForm.css`，各自以 `<style scoped src="./AuthForm.css" />` 引入。
- 正文 `.auth-panel__mid` 独立滚动，外观切换和页脚保留在视口内。980px 以下改成品牌行加表单列；短窗口中的注册、验证和重置表单仍可完整访问。
- 验证码提供 `one-time-code` 与数字输入提示，密码和邮箱保留自动填充语义，提交中表单暴露 `aria-busy`。

### 1.1 五个表单态

登录页采用单页五态 + 扫码面板设计，通过内部 `mode` 控制，不额外占用浏览器路由：

```
                    ┌─────────────────────────┐
                    │      signin (登录)      │
                    └───────────┬─────────────┘
          「注册」              │              「忘记密码」
       ┌───────────────────────┼────────────────────────┐
       ▼                                                ▼
┌──────────────┐                                ┌───────────────┐
│ signup (注册)│                                │ forgot (找回) │
└──────┬───────┘                                └───────┬───────┘
       │ 提交注册 (发邮件)                              │ 发送重置码
       ▼                                                ▼
┌──────────────┐                                ┌───────────────┐
│ verify (验证)│ ────────── 验证通过 ─────────► │ reset (重置)  │
└──────────────┘                                └───────┬───────┘
       │                                                │ 重置成功
       └────────────────── 登录成功 ◄───────────────────┘
```

- **`signin`**（`SigninForm.vue`）：账号/邮箱 + 口令登录，「忘记密码」贴在密码 label 行右端；底部按 `GET /api/auth/options` 动态渲染启用的第三方方式（未配置的 provider 不渲染）。
- **`signup`**：邮箱 + 口令 + 确认口令 + 强度提示（长度优先原则），提交后转入 `verify` 态。
- **`verify`**：6 位邮箱验证码输入，附带 60s 重发倒计时。
- **`forgot` / `reset`**：邮箱找回密码与新密码重置流。
- **URL Query 联动**：
  - `?claim_state=`：第三方 OAuth 302 授权跳回后自动执行 session 兑换。
  - `?verify_token=`：邮件直连邮箱验证。
  - `?reset_token=`：邮件直连密码重置。
  - `?auth_error=`：展示第三方授权错误。
  - `?mock_state=`：直接呼出演示扫码面板。

## 2. 扫码状态机 (QrLoginPanel)

外部扫码登录统一由 `QrLoginPanel.vue` 承载，内置轻量轮询（2s 一次）与页面可见性监听（切换后台暂停轮询）：

```
[ pending (待扫描) ] ──(手机扫码)──► [ scanned (已扫码待确认) ] ──(手机点确认)──► [ confirmed (已确认) ]
       │                                     │                                      │
       ├─────────(超时 5 分钟)───────────────┤                                      │ 自动调 claim
       ▼                                     ▼                                      ▼
[ expired (已过期, 可点击刷新) ]     [ failed (失败/异常) ]                  [ consumed (已进入) ]
```

二维码样式位于 `QrLoginPanel.css`，通过 scoped src 引入。扫码区保留 210px 扫描面积；过期和失败遮罩使用不透明表面色，并提供可聚焦的「刷新二维码」/「重试」按钮。轮询、过期、兑换会话仍由同一状态机驱动。

### 二维码渲染取舍
- **方案**：采用纯前端轻量 QR 编码器（`frontend/src/shared/lib/qrcode.ts`，支持 Byte 模式 + EC Level M + SVG 渲染，零外部依赖）。
- **降级机制**：若二维码由于异常无法渲染，降级展示链接文本与 state 码。

## 3. 当前用户 Store (`useUserStore`)

- **数据字段**：`user`（`UserProfile`）、`quota`（配额）、`loading`、`initialized`。
- **计算属性**：`authenticated`、`isAdmin`、`mustChangePassword`。
- **方法**：
  - `load()`：轻量拉取 `/api/auth/session`，供路由守卫与首屏使用。
  - `refresh()`：全量拉取 `/api/auth/me`（含配额、会话、身份绑定）。
  - `logout()`：退出登录并清理 Store 状态。
  - `patchProfile(payload)`：更新个人资料并同步 Store。

## 4. 账号中心 (`AccountView.vue`)

路由 `/account`。身份条走 `PageToolbar`（头像 / 昵称 / 角色 / 邮箱），分区走 `PageTabs`，正文满幅。四个功能 Tab：
1. **个人资料**：账号名、昵称、头像 URL、简介编辑。
2. **安全设置**：修改密码（强度读数与「更新密码」并入小节标题行）、登录设备（标题行带会话计数与「下线其他会话」）、第三方账号绑定/解绑。
3. **资源配额**：只读展示 LLM Monthly Tokens、Daily Calls、私有策略槽位、发布槽位等配额（-1 格式化为「不限」）。
4. **开放 API**：API Key 列表（标题行带条数与「新建 API Key」）、新建 API Key（新建后明文仅展示一次并支持一键复制）、撤销 API Key。

账号正文由 `AccountView.css` 约束内层滚动；资料、安全、配额、API 分区统一使用中性表面与令牌间距。安全设置按响应式栅格排列，设备及第三方身份长文本可换行；API Key 的一次性明文框可完整选中，窄屏时复制按钮换行。`AccountSecurityPane.css` 与账号样式均采用 scoped src。密钥新建、明文结果弹层使用 `dialog-body--scroll`，不裁切底部操作。
