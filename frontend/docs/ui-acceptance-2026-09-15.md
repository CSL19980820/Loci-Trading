## 复验入口与证据

在 `frontend` 目录运行：

```powershell
bun run typecheck
bun run test
bun run build
node e2e/ui-finish.mjs
```

`ui-finish.mjs` 可通过 `UI_AUDIT_WIDTHS`、`UI_AUDIT_HEIGHT`、`UI_AUDIT_THEMES`、`UI_AUDIT_SCENES` 选择范围。设置 `AUDIT_BASE` 时只允许本机预览地址；不设置时启动一次性开发预览并在结束时关闭。脚本复用已安装的 Chromium，不调用真实模型。

证据保留在 `frontend/artifacts/ui-finish/evidence/`：`summary.json`（结果、源文件及构建入口校验值）、`browser-cases.json`（212 项明细）、`checks.log`（核验摘要）和 7 张代表性截图。中间试跑截图、失败日志及临时验证脚本在证据整理后删除；持久回归脚本与测试代码保留。
