# 移动端页面层重构

## 范围

手机使用独立呈现结构，桌面继续保留工作台布局；共享现有 API、账户状态、权限、交易与财务计算。不得改变账本、买卖规则或回撤口径。

## 交付顺序

1. 统一手机布局断点、页面滚动拥有者、触控尺寸、底部安全区及键盘行为；保留返回时的筛选、页码和位置。
2. 重排盘面、候选池、个股档案、选股、策稿和胜率，不在手机上简单堆叠桌面卡片。
3. 重排交易员持仓、研判、报告、经验与对话；持仓曲线独立页签，默认单张回撤图。
4. 配置、账户、后台使用适合手机的导航与表单；管理员/访客能力不变。
5. 以实际页面操作和截图验收，再执行仅前端增量发布，保留旧资源及回滚镜像。

## 视觉与交互

- 同页只保留一个主要纵向滚动区。长表与图表可以有明确的横向操作区，不能形成多层纵向滚动陷阱。
- 页面标题、当前上下文与主要动作不重复；按钮文案不逐字换行。
- 主要数据和任务优先进入首屏；次要配置和完整证据在可发现的详情入口中。
- 普通文字保持可读，不靠缩小字号塞入内容。金额、百分比、日期分别格式化并保持单位。
- 弹窗距可见视口顶部 5%，内容与底部动作可达。键盘打开时不被底部导航覆盖。
- 缺失数据、陈旧估值、区间口径明确；风险状态不用“安全”代替未触及预警。
- 回撤到预警线的距离使用“个百分点”；恢复至峰值的涨幅不改写成“距前高”。

## 验收路径

盘面 → 候选 → 档案 → 返回原候选；智能体 → 持仓 → 对应个股曲线 → 今日研判 → 历史；报告选择与阅读；策稿输入与结果切换；筛选取消、设置未保存返回、访客只读、旧标签页跨版本导航。

每条路径检查首屏重点、中文与长值、单手点击、滚动、键盘及返回状态。分别使用 360/390/430 宽手机视口、较矮可见视口、明暗主题，并回归桌面。模拟夹具、真实接口和线上资源验证分别记录，不混作同一种验收。
