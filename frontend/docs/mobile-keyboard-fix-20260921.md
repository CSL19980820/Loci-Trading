# 移动端输入键盘收起问题：修复与上线回执

2026-09-21 18:25:11（北京时间）部署 `loci-qianlong:ui-20260921-182236`。

## 原因与修改

`MobileBottomNav.vue` 的 scoped 样式原为 `:global(html[data-mobile-keyboard]) .mobile-bottom-nav { display:none; }`，实际编译结果丢失后面的导航选择器，成为 `html[data-mobile-keyboard]{display:none}`。键盘弹出缩小视口时，整个文档被隐藏，输入框失焦，键盘随即收起。

改为将完整选择器放入 `:global(...)`。编译结果只隐藏 `.mobile-bottom-nav`，保留网页与输入焦点。添加编译后选择器的回归测试，验证键盘状态下命中的仅为导航。

## 发布范围
