# 前端导览

## 当前基础

Vue 3、TypeScript、Vite、Tailwind CSS 4、Pinia / Colada、Vue Router。
界面采用可编辑源码形式的 shadcn-vue / Reka UI；图标来自 `@lucide/vue`，消息提示来自 `vue-sonner`。
准确依赖版本以 `package.json` 和 `bun.lock` 为准，避免在指导文件里另存容易过期的版本清单。

`features/` 按业务组织；`shared/components/ui/` 放界面原语和通用组合组件，`shared/api/` 放接口，`shared/stores/` 放共享状态。
`BasicTable`、`BasicForm` 等保留业务封装；它们的实现与接口可以因真实需求演进，并非所有页面必须套用同一模板。
`components.json` 描述 shadcn-vue 生成路径。主题实现见 `style.theme.css`、`style.tw-theme.css` 和 `shared/lib/theme.ts`。

## 可参考的经验

- 表格、表单、对话框和助手输入应保留已有有效交互；优先检查输入、选择、验证、取消、键盘焦点和长内容，而不只确认编译成功。
- 图表和编辑器可按使用场景延迟加载，避免为了统一分包把所有业务一次拉进首屏。
- 表单回写时的结构相等比较、请求世代或 AbortSignal、监听器对称释放，分别有助于避免更新循环、过期结果覆盖及资源泄漏。
- 主题与密度应服务任务。字号、留白、颜色、圆角、阴影、布局和组件选择都可调整；`docs/ui-spec.md` 只是设计建议。
- 浏览器夹具适合隔离测试。模拟数据验证、本地真实接口验证和生产验收是不同证据，不互相冒充。

## 常用入口

开发预览使用 `bun run dev`；测试、类型检查和构建入口见根目录 `AGENTS.md`。

依照改动范围选用这些命令或其他合适工具。共享控件和主题变更通常值得补充代表性页面、窄屏及不同外观的浏览器检查；单元测试可围绕用户可见行为，而不是某个组件库的内部类名。

shadcn-vue 的组件代码属于仓库，可直接改进。生成器输出也只是起点，没有必须机械保留的模板；新增依赖前评估维护状态、可访问性、性能和与现有业务的适配程度。
